# 🧩 插件功能规划（pi 版）

**一句话：** 把需求拆成功能清单与优先级，画数据流。

## 激活方式

```
根据需求文档，帮我列出功能清单（P0/P1/P2），并画出 content → popup → storage 的数据流
```

## 涉及资源

- **Skill**: `game-design`（MVP、功能分层）
- **Skill**: `extension-content-scripts`（页面交互边界）
- **Skill**: `extension-popup-ui`（界面能力边界）

## 产出

- 功能清单（P0 最小闭环 / P1 / P2）
- 数据流图（各上下文职责与消息通路）
- 存储 schema 初稿
- 可选：写入 `设计文档/` 的功能规格

## 协作协议

先定 P0 闭环，P1/P2 留作迭代；避免一次做全家桶。
