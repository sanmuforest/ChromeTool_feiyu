# 📝 撰写产品设计文档（pi 版）

**一句话：** 按模板产出可评审、可开发的设计文档。

## 激活方式

```
按照 game-design skill 的模板，把功能规划写成设计文档，放到 设计文档/ 下
```

## 涉及资源

- **Skill**: `game-design`（设计文档模板）

## 产出

- `设计文档/` 下的设计文档，含：
  - 一句话定位
  - 用户故事与场景
  - 功能清单（入口/交互/输出）
  - 权限与数据（manifest 权限、存储结构）
  - 边界情况
  - 实现要点

## 协作协议

文档写意图不写实现细节；实现细节以代码为准，避免文档代码冲突。
