# 🐞 Bug 报告与测试计划（pi 版）

**一句话：** 建立测试计划，复现并记录缺陷。

## 激活方式

```
帮我写测试计划（单测/集成/E2E 分层），并把这个 bug 记录为可复现的报告
```

## 涉及资源

- **Skill**: `extension-testing`（测试金字塔、Playwright E2E）
- **Skill**: `extension-prototype`（手动验证路径）

## 产出

- 测试计划（单测对象清单、E2E 场景）
- Bug 报告（复现步骤、期望/实际、环境、影响范围）
- 回归测试（每个修复附带）

## 协作协议

Bug 报告必须可复现（含页面 URL 与操作步骤）；修复后由报告者验证关闭。
