# 🛡️ 安全与权限检查（pi 版）

**一句话：** 按安全基线审查权限、注入、数据与通信。

## 激活方式

```
用 extension-security 审查：权限是否最小、有无 XSS 注入点、敏感数据怎么存的、消息是否校验
```

## 涉及资源

- **Skill**: `extension-security`（安全自查清单）
- **Agent**: `extension-specialist`（合规把关）

## 产出

- 权限清单审计结论（每项权限的用途说明）
- 注入点与 XSS 风险修复
- 数据收集声明（隐私政策草案）
- Web Store 合规自查结论

## 协作协议

安全项没有「以后再说」；上架前必须清零所有安全阻断项。
