# 🔍 代码审查与质量检查（pi 版）

**一句话：** 按审查清单全面检查代码与配置。

## 激活方式

```
用 extension-review 审查 src/ 全部代码和 manifest.json，按阻断/建议/风格输出问题清单
```

## 涉及资源

- **Skill**: `extension-review`（审查清单）
- **Agent**: `reviewer`（代码质量把关）

## 产出

- 问题清单（阻断 / 建议 / 风格，含文件与行号）
- 阻断项修复后复验结论
- 可选：质量门禁（lint/typecheck 接入）

## 协作协议

阻断项必须清零；修复后重新审查确认，不留口头承诺。
