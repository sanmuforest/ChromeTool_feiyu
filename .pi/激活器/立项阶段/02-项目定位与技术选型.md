# 🎯 项目定位与技术选型（pi 版）

**一句话：** 明确插件边界，选定技术栈与权限模型。

## 激活方式

```
帮我确定这个插件的技术方案：TypeScript + Vite 构建、权限清单怎么定、有没有更轻的做法
```

## 涉及资源

- **Skill**: `extension-dev`（MV3 约束、项目结构）
- **Agent**: `extension-specialist`（架构与权限模型）
- **Skill**: `extension-security`（权限最小化基线）

## 产出

- 插件边界（做什么、明确不做什么）
- 技术栈选型（构建工具、UI 方案、测试工具）
- manifest 权限初稿（最小权限 + 说明）
- 可选：写入 `设计文档/` 的技术选型记录

## 协作协议

技术选型先对比方案再定，记录取舍理由，不直接进入编码。
