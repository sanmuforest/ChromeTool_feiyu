# 💡 创意与需求梳理（pi 版）

**一句话：** 从零发散插件概念，或围绕现有痛点深入挖掘。

## 激活方式

直接描述你的想法，或让 pi 引导：

```
我想做一个浏览器插件，解决我每次在网上看长文章都要手动复制的麻烦，帮我梳理需求和价值
```

## 涉及资源

- **Skill**: `game-design`（价值循环、MVP 原则）
- **Agent**: `extension-specialist`（插件生态与可行性判断）

## 产出

- 插件概念方向（一句话定位）
- 目标用户与典型使用场景
- 核心价值循环草图
- 可选：写入 `设计文档/` 的需求文档

## 协作协议

头脑风暴阶段先出方案讨论，不写代码。
