# 🔌 Pi Extension Studio — 功能激活器（pi 版）

> **不想记命令？从这里挑你需要的，拖进 pi 聊天窗口即可。**

## 使用方法

1. 浏览下方分类文件夹
2. 每个文件对应一个独立功能或功能群组
3. **文件名 = 功能简述**，看一眼就知道是干什么的
4. 把选中的 `.md` 文件**直接拖进 pi 聊天窗口**
5. pi 读取后会自动启动对应 skill / 智能体 / 工作流

## 分类说明

| 文件夹 | 用途 |
|--------|------|
| `立项阶段/` | 需求梳理、技术选型 |
| `设计阶段/` | 功能规划、设计文档、设计评审 |
| `开发阶段/` | 架构搭建、内容脚本、界面、后台服务 |
| `测试与质量/` | 代码审查、Bug 报告、安全权限 |
| `优化与发布/` | 性能优化、发布检查与上架 |

## 对应的 pi 资源

- **Skills**：`.pi/skills/`（extension-dev、extension-review、extension-prototype 等 10 个）
- **智能体**：`.pi/agents/`（scout、planner、worker、reviewer、extension-specialist）
- **主题**：`.pi/themes/extension-theme.json`（思考文字淡黄色）
