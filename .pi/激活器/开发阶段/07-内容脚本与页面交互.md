# 🕷️ 内容脚本与页面交互（pi 版）

**一句话：** 实现页面数据提取、注入 UI、与后台通信。

## 激活方式

```
按 extension-content-scripts 规范，实现 content 脚本：提取页面数据、处理动态加载、样式隔离
```

## 涉及资源

- **Skill**: `extension-content-scripts`（注入、提取、MutationObserver、样式隔离）
- **Skill**: `extension-perf`（注入成本控制）

## 产出

- content script（提取逻辑为纯函数 + 可单测）
- 注入的 UI 元素（带前缀样式 / shadow DOM）
- 消息通路（content ↔ background ↔ popup）
- 动态页面变化处理（MutationObserver + 节流）

## 协作协议

提取逻辑先做成纯函数并用单测验证，再接 UI；遇到页面结构变化先确认锚点稳定性。
