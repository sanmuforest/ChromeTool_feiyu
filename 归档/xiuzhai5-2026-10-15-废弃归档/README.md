# xiuzhai5 站点定义（已废弃归档）

- **废弃日期**：2026-10-15
- **废弃原因**：该站**大部分链接会跳转到付费**（用户实测反馈）→ 适配意义有限，用户决定放弃
- **处理方式**：定义文件从 `src/sites/defs/` 移入本归档目录，并从 `defs/index.ts` 注册表与抓取页站点列表移除
- **原定义要点**（供将来参考）：
  - 相册 `/{id}`：第 1 页不带参数，其后 `?page=N`（实测共 7 页，**每页正文 20 张**）
  - 正文容器 `div.article-fulltext`（**与 buondua 同一套模板**，xiuren 系）
  - 正文图床 `img.xiuzhai5.com/yishijie/photo/uploadfile/{年月}/{日}/{hash}.jpg`
  - 正文图**懒加载**：`src` 是占位图 `/img/load.gif`、真图在 `data-src`
  - 底部推荐位图床同为 `img.xiuzhai5.com`（路径含 `/pic/`）→ 统计正文张数须以容器内为准
  - 标题 `{相册名} - 第 N 页`（无站名后缀）
- **附带产出（保留在引擎中，不回滚）**：v0.2.46 的「懒加载 `data-src` 支持 + 占位图过滤」属通用能力，
  是本次适配过程中通过真实页面验证发现的，对其它站点同样有效
