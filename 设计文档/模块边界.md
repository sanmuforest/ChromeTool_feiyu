## 职责边界

### 日志系统（`src/lib/logger.ts`）— 全项目核心

- **唯一写入者**：background 的 `appendLog` 直写 storage；grabber/content 必须通过消息 `LOG_ADD` 转发
- 其他模块**禁止直接读写** `log_buffer` / `log_level` 存储键
- 打日志统一用 `initLogger(context)` 返回的 logger 对象，禁止裸 console 替代（调试期临时除外）

### 共享抓取视图（`src/grabber/image-grab-view.ts`）— 高影响面组件

- **命名顺序约定（2026-10-06 定稿，不得回退）**：下载 / 打包的文件编号 `001-N` = `images` 数组顺序 = **抓取顺序**
  （多页图站 = 页序 × 页内 DOM 序；imgbb = 翻页序；主抓取页 = DOM / 滚动序）
- **禁止**在 `collectSelectedItems` 中按 URL 字典序、文件名或其它键重排（历史 bug：hash / base64 命名的站点编号与页面顺序错位，见 `变更日志/2026-10-06-001`）
- 该组件的任何改动会影响全部抓取场景：主抓取页 / imgbb 用户主页 / imgbb 相册 / 多页图站单相册 / 多页图站批量 / 聚合搜索批量抓取 —— 改动须做全场景回归

### 图站模块（`src/sites/`）— 多页站点适配唯一来源（FP-018）

- **域名单一来源**：站点域名只允许出现在 `defs/*.ts` 的 `endpoints`（role: primary/mirror/search）与 `searchBaseHost`；业务代码**禁止**出现 `https://域名` 字面量，URL 一律由 `engine.ts` 用 host + 路径/参数拼装
- **禁止按站点 id 硬编码分支**：搜索页解析、张数提取、推荐/其他链接扫描、翻页节流、文件夹前缀一律读定义字段（`linkParser` / `imageCountRule` / `scan` / `throttle` / `folderTag`），新增站点只加 `defs/*.ts` 一份数据
- **命名约定**：文件夹名 `ID-{folderTag}-*`；阶段 1 全部站点 `folderTag='buondua'` 以维持既有命名，**语义化改名属行为变更，须另行申请**
- **顺序敏感**：`defs/index.ts` 的 `SITE_DEFS` 顺序 = 聚合搜索「Google 全站」站点遍历顺序，调整须回归
- **定义必须保持纯数据**（无函数）：否则无法支持 UI 编辑 / 导入导出 / 探测生成
- 阶段 1B（计划）：运行期域名单点覆盖（storage `sites_endpoints`）+ 站点分组由 `channels` / `defaultChecked` / `uiOrder` 派生
- **Google 通道限频纪律（FP-024；用户实测结论：密集高频请求会触发 Google 反爬）**：禁止移除或放宽 `GOOGLE_TAB_INTERVAL_MS`（请求间隔 4s）、`GOOGLE_MAX_REQUESTS_PER_RUN`（单轮预算 8 次）、`GOOGLE_COOLDOWN_MS`（被拒冷却 15 分钟）三道限制；测试时禁止短时间反复发起搜索（每轮间隔建议 ≥1 分钟），优先使用站内搜索与列表浏览

## 禁止事项（跨模块雷区）

1. 类型/存储/日志三个基础模块**内部实现**改动 = 重大变更，须先说明再改
2. grabber / content **不得绕过消息直接写** `log_buffer`、`grab_sessions`

## imgbb 适配器专规（FP-003）

- **数据通道**：场景 2/3/4 后台 fetch（imgbb 公开页：/albums、ibb.co/album/{ID}、/following、/followers）；场景 1 用户主页受登录墙保护，主通道为 content script 注入（用户在 imgbb 页面内操作），后台 fetch 失败时提示
- **原图规则**：列表项 `data-object` JSON 的 `image.url` 即原图（最大尺寸），`medium.url` 展示图、`thumb.url` 缩略图；禁止误用列表页 img src（那是展示图）
- **登录墙**：`isLoginWall` 检测 `<title>Sign in`；后台请求一律检测，命中即抛 `LoginWallError`
- **页面解析仅允许 imgbb 域名**：`*.imgbb.com` / `ibb.co` / `i.ibb.co`
