## 职责边界

### 日志系统（`src/lib/logger.ts`）— 全项目核心

- **唯一写入者**：background 的 `appendLog` 直写 storage；grabber/content 必须通过消息 `LOG_ADD` 转发
- 其他模块**禁止直接读写** `log_buffer` / `log_level` 存储键
- 打日志统一用 `initLogger(context)` 返回的 logger 对象，禁止裸 console 替代（调试期临时除外）

### 存储层（`src/lib/storage.ts`）

- 所有 chrome.storage 读写必须经此封装；存储键命名必须注册在下方「存储键注册表」

### 消息协议（`src/lib/messages.ts`）

- 新增消息必须：① 在此定义类型 ② 在 background 的 `handleMessage` 加分支 ③ 在注册表登记
- 响应一律 Promise 模式
- 路由约定：content 上报经 background 按 `sender.tab.id` 路由；bg→grabber 转发用 `*_FWD` 后缀；grabber 只处理 `*_FWD`

## 禁止事项（跨模块雷区）

1. 类型/存储/日志三个基础模块**内部实现**改动 = 重大变更，须先说明再改
2. grabber / content **不得绕过消息直接写** `log_buffer`、`grab_sessions`
3. 新增 content script 匹配规则须评估权限影响（当前用 activeTab 动态注入，无静态声明）
4. 打包下载依赖 `optional_host_permissions`（`<all_urls>`），仅在用户点打包时按需申请；不得提前申请
5. 任何模块改动后须自查相邻模块（回归检查），结论记入变更日志

## imgbb 适配器专规（FP-003）

- **数据通道**：场景 2/3/4 后台 fetch（imgbb 公开页：/albums、ibb.co/album/{ID}、/following、/followers）；场景 1 用户主页受登录墙保护，主通道为 content script 注入（用户在 imgbb 页面内操作），后台 fetch 失败时提示
- **原图规则**：列表项 `data-object` JSON 的 `image.url` 即原图（最大尺寸），`medium.url` 展示图、`thumb.url` 缩略图；禁止误用列表页 img src（那是展示图）
- **登录墙**：`isLoginWall` 检测 `<title>Sign in`；后台请求一律检测，命中即抛 `LoginWallError`
- **页面解析仅允许 imgbb 域名**：`*.imgbb.com` / `ibb.co` / `i.ibb.co`

## ~~freeimage 适配器专规（FP-007）~~ 已废弃

> 2026-08-13 废弃（freeimage.host 图片质量不佳），插件内代码已删除，归档：`归档/freeimage-2026-08-13-废弃归档/`。以下仅保留历史记录。

- **数据通道**：全部公开页，后台 fetch 直连（无登录墙/无 Cloudflare）：
  - 用户主页图片：`https://freeimage.host/{user}?list=images&sort=date_desc&page={N}&ajax=1`（36 图/页）
  - 相册列表：`https://freeimage.host/{user}/albums?sort={sort}&page={N}`（36 项/页；sort: views_desc/date_desc/likes_desc/name_asc）
  - 相册详情：`/a/{slug}.{ID}`（新式）或 `/album/{ID}`（老式）；相册内图片翻页：`?list=images&from=album&albumid={ID}&sort=date_desc&page={N}&ajax=1`（6 图/页）
  - 探索页：`https://freeimage.host/explore?ajax=1&list=images&sort=date-added-desc&page={N}`（36 张/页）
  - 图片页属主：`/i/{id}` 的 user-link（匿名显示 Guest）
- **原图规则**：图片 data-object `image.url` 即原图（iili.io 直链，200 可下载）；`medium.url` 展示图、`thumb.url` 缩略图
- **域名白名单**：仅允许 `freeimage.host` / `iili.io`
- **标注库**：`fh_producer_db`（FROZEN 级受保护，唯一 owner = freeimage 适配器），grabber 不得绕过消息直接读写
- **扩散节流**：属主提取/相册名采集批内串行 + 间隔，连续 429 暂停提示（对齐 imgbb 节流经验）
