# 2026-08-10-024 用户主页/相册下载区补齐打包下载与打开文件夹

## 本次改动（view-adapters.ts）

用户主页与相册抓取两个子标签的下载区，由「下载选中」扩充为三个按钮：

| 按钮 | 功能 |
|------|------|
| 下载选中 | 原图队列下载（原有，进度在日志/下载管理器） |
| **打包下载**（新增） | JSZip 打包选中原图 → zip 下载；需 `<all_urls>` 权限（自动申请）；状态栏显示打包进度 |
| **打开文件夹**（新增） | 打开浏览器下载目录 |
