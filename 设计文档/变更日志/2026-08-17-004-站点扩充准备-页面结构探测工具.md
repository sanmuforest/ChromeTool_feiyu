# 2026-08-17-004-站点扩充准备：页面结构探测工具

## 变更（FP-014 站点扩充，前置工具）

新增「页面结构探测」：适配新站前，在抓取页输入相册 URL → 后台静默开标签 → executeScript 提取页面结构特征（标题/og:image/图片 src 样本/图片祖先容器 class 候选/分页链接）→ 关闭标签 → 面板显示。

用途：misskon.com / ilovexs.com / cangcuc.com / phimvuspot.com 四站适配的实测数据来源（沙箱无法访问站点，需用户配合探测）。

## 使用方式（配合新站适配）

1. 重载扩展 → 多页图站 → 抓取标签
2. 粘贴相册 URL → 点「探测结构」
3. 面板显示：标题 / og:image / 图片样本（前 8 条 URL 模式）/ 容器 class 候选（出现次数）/ 分页链接样本
4. 用户把输出贴回给开发侧 → 据此精确配置 GALLERY_SITES（containerOpen/pagePattern/pageUrl/cleanTitle）
