# 2026-08-11-057 标签云功能（FP-006）

## 概述

生产者库缓存相册名 → 多语言标签提取 → 统计生成标签云，点击标签自动触发相册检索。纯本地、零网络请求。规则经真实数据预研验证（32501 相册）。

## 新增模块

`src/lib/tag-extract.ts`（纯逻辑，ACTIVE）：

- 分类：演员（中文/日文整段）/ 韩语（谚文段）/ 主题 / 服装 / 品牌 / 英文（Capitalized 词序列）/ 引用
- 服装词：中文包含 + 英文独立词匹配（ol/jk/lolita/latex/cosplay/t，防字母误匹配——预研中 ol 曾误匹配 3276 相册）
- 品牌/编号剥离、停用词（英文描述 + 韩语通用 + 月份缩写）、拼音→中文合并、非中文注释词典
- 统计：相册数≥10 且 用户≥2 → 相册数降序 Top N（默认 100）

## 交互

- 点「生成标签云」/ 调 Top N → 云渲染（演员蓝/韩语紫/主题绿/服装粉/品牌橙/英文灰/引用青）
- **点击标签 → 自动填入③区关键词 → 触发检索**（includes 匹配，零请求）→ 滚动到结果区

## 验证方式

1. 重新加载 `dist/` → ② 区「生成标签云」
2. 标签云渲染（演员为主，服装/主题可见，非中文带注释）
3. 点击「黑丝」→ ③ 区自动检索 → 命中含黑丝相册
4. Top N 调 50/200 对比
