# 2026-08-13-075 聚合搜索修复：rrwsh 多域解析 + 反爬页污染过滤

## 背景（用户反馈）

聚合搜索两个问题：① `https://rrwsh.uuss.uk/pages/album`（rrwsh 站点）搜索失败；② pixibb 搜索成功但结果与关键词无关。

## 日志解读 → 根因 → 改动点

### 问题 1：rrwsh 搜索失败

- **根因**：rrwsh.uuss.uk 是 4khd 的镜像前端，搜索页的文章链接实际指向 **`https://www.4khd.com/content/{N}/{slug}.html`**（实测搜索页 100KB 中 0 个 rrwsh.uuss.uk 链接）。而 `parseSitePostLinks` 只匹配 `hosts[0]`（rrwsh.uuss.uk）→ 提取 0 条 → 搜索失败
- **改动点**：
  - `parseSitePostLinks` 改为接收 **hosts 数组**（匹配全部 host/子域）
  - `parseLinksForSite` 传 `site.hosts`（rrwsh 配置含 rrwsh.uuss.uk + 4khd.com）
  - 排除规则补充 `/pages/`（rrwsh 导航页混入）
  - 标题附近文本过滤 CSS/样式（`.is-style-no-margin {margin:0 !important;}` 被当标题）
  - 同 URL 多 a 去重改为 Map：封面 a 先出现（标题提取失败=URL），标题 a 后到者**补齐标题**
- 实测：rrwsh 搜索页解析 13 条，标题大部分正确（"Pure Media Vol.0247 321 Yeha..."、"季雨COS..."）

### 问题 2：pixibb 结果与关键词无关

- **根因**：jrants 搜索被反爬拦截时返回 **"Search Request Blocked" 页**（实测 2924 字节），该页含"热门文章"等链接，被 `parseJrantsPostLinks` 解析成**垃圾结果**混入 → 结果与关键词无关
- **改动点**：`searchSites` 每页 fetch 后加 `isBlockedPage()` 检测（Search Request Blocked / 安全验证 / Cloudflare / Turnstile 等），命中即跳过该站并报"搜索被反爬拦截（限流）"，不再产出垃圾链接

## 验证方式（用户实测，红线 3）
