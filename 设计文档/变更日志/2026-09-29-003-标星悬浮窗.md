# 2026-09-29-003 标星悬浮窗（FP-017）

## 需求（用户指示）

「可以在（相册）用户的相册页面加一个标星级的小悬浮窗」——在 imgbb 页面直接评星，无需回抓取页。

用户确认：标星对象 = 相册所属用户；覆盖 `*.imgbb.com` 用户页 + `ibb.co/album/*`；注入 = 按需授权 + 动态注册；库外用户标星自动入库。

## 权限说明（红线 1）

- `permissions` 数组**未变**（storage / downloads / activeTab / scripting）
- 仅新增**可选** host 权限条目；只有用户点「启用」并在 Chrome 提示中同意后，扩展才持有 imgbb 域权限
- 点「关闭」→ `unregisterContentScripts` 注销注入 + 开关落库为 false
- SW 启动时若开关为开但权限已失效 → 自动关闭开关并记 `[background/star]` 警告日志
- 未采用 manifest 静态 `content_scripts`（保持"用到才申请"的既有约定）

## 回归自查

- 抓取页「入度 Top」第 5 列评星行为不变（FP-015）
- 标签云、检索、扩散、下载链路未触碰
- content script 仍遵守「storage 读写经 `src/lib/storage.ts` 封装」约定（浮窗位置/折叠状态走封装）

## 已知限制

- 单图页 `ibb.co/<id>` 不显示浮窗（避免每页一次属主解析）
- 已打开的 imgbb 页面需刷新一次才出现浮窗（动态注册不回溯）
- 相册级星级未实现（用户选择只做用户星级）
