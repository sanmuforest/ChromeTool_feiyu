# 2026-08-10-021 修复：关注墙选项按钮 + imgbb 后台权限申请

## 根因排查（用户反馈）

1. **关注墙报错的真正根因**：019 的多编辑调用整体失败，HTML 里的 select **从未加入**——但代码却读取 `#following-side` → null 报错
2. **「获取错误」（相册 T45x7F 用户名解析失败）**：后台 fetch imgbb 页面需要 `<all_urls>` host 权限，未授权时被 CORS 拦截；自动填充的用户名解析也在未授权时静默失败

## 本次改动

1. **关注墙选项改 radio 按钮**：分析按钮前新增「全部 / 关注者 / 被关注者」单选按钮组（替代未生效的 select）；切换方向自动清空结果并提示重新分析
2. **host 权限主动申请**：`ensureHostPermission()`——所有 imgbb 后台操作（用户主页/相册/相册分析/关注墙）点击时检查并在手势内申请 `<all_urls>`；拒绝则明确提示
3. **自动填充容错**：相册页用户名解析前检查权限，未授权则提示「点击任意分析按钮时请求授权」，不再静默失败
