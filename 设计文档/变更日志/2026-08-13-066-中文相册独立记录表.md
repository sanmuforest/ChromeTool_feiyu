# 2026-08-13-066 中文相册独立记录表（FP-007 v11）

## 背景

用户反馈：
1. 手动种子/深挖概念不好理解，不起效
2. 需求简化：常规检索 + 中文过滤（直接跳过非中文）+ 中文相册单独记录为独立数据表

## 方案（v11）

**弱化深挖概念，聚焦「常规检索 + 中文过滤 + 独立中文表」**：

1. 探索检索的中文相册**自动单独存入独立表** `fh_cn_album_index`（中文相册检索记录）
2. 「仅中文」checkbox：全量表只存中文（跳过非中文）
3. ④ 区块改为**中文相册检索记录**：读独立表（显示全部 + 中文关键词检索 + 导出/导入/清空）
4. 深挖保留为「中文用户补充」（可选）：种子输入支持用户名或完整 URL，结果同步中文表
