# 2026-10-10-005 多页站性能回归修复 + 尺寸筛选按钮恢复

> 版本：**v0.2.20** ｜ 类型：性能回归修复（3 处）+ 功能修复（1 处）
> 触发：用户反馈多页图站抓取「① 图多后整页卡顿、滚轮都卡 ② 尺寸筛选按钮消失 ③ 重新抓取按钮消失」

## 问题定位

### 问题 1：整页卡顿（3 处性能回归，均为 2026-10-10 几轮修复引入）

| # | 回归点 | 原因 |
|---|--------|------|
| a | `wheel-forward.ts` 的滚动容器查找 | 用 `querySelectorAll('*')` 遍历面板内**全部元素**并**逐元素 `getComputedStyle`**；图片网格有上千元素，滚轮期间每 300ms 重查一次 → 反复触发大规模样式计算 → **滚轮卡顿** |
| b | `image-grab-view.ts` 的补尺寸回调 | 每张图 `load` 后都调用 `updateStats()`，而它内部 `applyDedupe → applyFilter → applySmallFilter` 是多次 O(n) 遍历；尺寸筛选的 `buildSizeGroups()` 更是 O(n²) 量级 → 数百张图 = 数百次全量计算 |
| c | 错峰加载破坏 `loading="lazy"` | 按渲染顺序无条件 `setTimeout` 设 `src`，数百张图会**全部**进入加载队列（lazy 形同失效）→ 内存与解码压力暴涨 |

### 问题 2：尺寸筛选按钮消失

- 尺寸筛选按钮由 `buildSizeGroups()` 依据**已测得尺寸**的图片生成；多页图站的图片由后台解析（无宽高）→ `sizeStatus` 恒为 `unknown` → 分组为空 → 只显示「解析完成后在此按尺寸筛选」提示文案
- v0.2.19 加入「加载后补齐尺寸」后，**只调用了 `updateStats()`，没有重建尺寸筛选** → 即使尺寸补齐了，按钮也不会出现

### 问题 3：重新抓取按钮消失

多页站创建共享视图时显式传了 `showReparse: false`（**既有设计**：多页站的重抓入口是面板上方的「抓取全部子页」按钮）→ 属预期行为，**待用户确认是否需要改动**。

## 改动

| 文件 | 改动 |
|------|------|
| `src/grabber/wheel-forward.ts` | ① 候选容器由 `'*'` 改为**已知布局容器选择器**（`.grid` / `.img-grid` / `.bd-link-list` / `.bd-batch-results` / `.log-list` / `.adapter-panel` 等），候选数从上千降到个位数；② 去掉无谓的 `getBoundingClientRect`；③ 缓存 300ms → **1500ms** |
| `src/grabber/image-grab-view.ts` | ④ 缩略图改为 **IntersectionObserver 按需加载**（`rootMargin: 300px`，接近视口才加载，同批 80ms 小步错峰）—— 同时恢复 `loading="lazy"` 的语义与错峰防限流的目标 |
| 同上 | ⑤ 新增 `scheduleBackfillRefresh()`：尺寸补齐后**去抖 400ms** 批量刷新，且**同时重建尺寸筛选按钮与统计**（修问题 2） |
| 同上 | ⑥ `renderGrid` 重建前 `thumbObserver.disconnect()`，避免观察器持有已移除节点 |

## 用户实测清单

1. 重载 `dist/`（确认徽标 **v0.2.20**）→ 多页图站抓一个**大相册**（几百张）
2. **卡顿**：滚动应顺畅；缩略图**滚到哪加载到哪**（不再一次性全load）；滚轮在留白处也应有响应
3. **尺寸筛选**：图片陆续加载完成后，工具栏的尺寸筛选按钮应**自动出现**（按尺寸分组，带数量）
4. 回归：主抓取页、imgbb 相册各抓一次，筛选/去重/选择/下载正常

## 说明

- 滚动容器候选选择器是**可枚举**的：若发现某个页签的留白滚轮不生效，把该页签的滚动容器 class 加进 `SCROLLER_CANDIDATES` 即可（性能与覆盖面之间的取舍：宁可不生效，也不要全树遍历拖慢滚动）
- 尺寸筛选按钮现在会在补齐尺寸后**自动出现**；由于是去抖刷新，按钮可能出现得比图片略晚（约 0.4s）

## 待确认（问题 3）

多页站共享视图当前隐藏「重新解析」按钮（`showReparse: false`）。若希望在视图工具栏内也提供「重新抓取」（重抓当前相册 URL），需要为多页站补一个 `onReparse` 回调并在 `view-buondua.ts` 传入 —— 属小功能，等用户确认后实施。
