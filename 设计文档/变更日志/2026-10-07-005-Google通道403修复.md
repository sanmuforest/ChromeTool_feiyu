# 2026-10-07-005 Google 通道修复：403 根因与 URL 现代化（FP-022）

> 版本：**v0.2.9** ｜ 关联：`设计文档/功能规划书/FP-022-Google通道健壮性.md`
> 触发：用户贴出 Google 403 错误页

## 日志解读

用户提供的页面文本：

```
403. 这是个错误。
您的客户端没有权限 /search?q=无痕丝袜&sitesearch=hitxhot.org&gbv=1 从此服务器获取 URL。
```

- 这是 **Google 服务器返回的 403**，被拒 URL = 插件为 hitxhot 构造的 Google 站内搜索地址
- 该 URL 中 `gbv=1`（基础 HTML 版）与 `sitesearch=`（老站内搜索参数）**均已被 Google 废弃**
- 代码中三处构造同类 URL（`engine.ts` 的 google-sitesearch 分支、`buondua-service.ts` 的 `googleSearchConfig`、`testGoogleConnection`）→ **整条 Google 通道失效**
- 与用户此前遇到的「人机验证」很可能同源

## 根因

| 项 | 结论 |
|----|------|
| 直接原因 | Google 拒绝带 `gbv=1` / `sitesearch=` 的请求（403） |
| 影响范围 | hitxhot / kaizty / jrants 的搜索、Google 全站模式、Google 连接测试 |
| 是否重构回归 | 否 —— 该 URL 构造方式在重构前后逐字一致（等价性对比覆盖） |

## 改动

| 文件 | 改动 |
|------|------|
| `src/sites/engine.ts` | `google-sitesearch` 分支：`q={词}&sitesearch={host}&gbv=1` → `q={词} site:{host}&hl=zh-CN` |
| `src/background/buondua-service.ts` | `googleSearchConfig` 同步改现代语法（Google 全站模式 / Google 组） |
| `src/background/buondua-service.ts` | `searchGoogleViaTab` 返回值新增 `blocked`；被拒时停止翻页且**保留标签页**（不再自动关闭） |
| `src/background/buondua-service.ts` | `extractGoogleTabResults` 返回 `{ items, blocked }`，识别 Google 拒绝/验证页特征（仅在无结果且命中特征时判定） |
| `src/background/buondua-service.ts` | 聚合搜索：被拒时给出明确提示，且**不再自动降级站内 fetch** |
| `src/background/buondua-service.ts` | `testGoogleConnection`：测试 URL 去掉 `gbv=1`；`blocked` 由硬编码 `false` 改为真实判定 |

## 回归检查

| 相邻模块 | 结论 |
|---------|------|
| 站内搜索通道（buondua 等） | 未触碰；仍走站点自身接口 |
| Google 组站点（hitxhot/kaizty/jrants） | URL 语法变化；解析仍走标签页渲染 + `cleanGoogleResult` |
| Google 全站模式 | 与 `googleSearchConfig` 共用同一 URL 语法，已同步 |
| 单相册 / 批量抓取 | 未触碰 |
| 「测试 Google 连接」按钮 | 返回值语义不变，`blocked` 现在反映真实状态 |
