# 2026-08-14-081 版本编号规则：v0.1.NNN 每轮更新末位 +1

## 背景

用户实测插件可正常加载后，要求版本编号采用 `v0.1.001` 格式，每轮功能更新后末位 +1。

## 本次改动

| 文件 | 改动 |
|------|------|
| `manifest.json` | version `0.1.0` → `0.1.001`（显示徽标 `v0.1.001 · 构建时间戳`） |
| `package.json` | version 同步 `0.1.001`；scripts 新增 `bump` |
| `scripts/bump-version.mjs` | **新增**版本递增脚本：解析 version 末位 +1（保留位宽补零），同步写回 manifest.json 与 package.json |
| `AGENTS.md` | 项目上下文版本规则更新：每轮更新后执行 `npm run bump` |
| `dist/` | 重新构建，manifest 版本 0.1.001 |

## 版本规则（已写入 AGENTS.md）

- 格式：`v0.1.NNN`（NNN 三位补零）
- 每次功能更新/修复交付前执行 `npm run bump`（0.1.001 → 0.1.002 → 0.1.003 ...）
- 构建时间戳徽标照旧（`vX.Y.Z · 构建时间戳`），测试报告必须核对徽标版本

## 验证方式

1. `npm run bump` 实测：0.1.001 → 0.1.002 ✅（验证后已改回 0.1.001 作为起步版本）
2. `npm run build` 通过；dist/manifest.json version = 0.1.001
3. Chrome 加载 `dist/` 后核对扩展列表版本与抓取页右下角徽标 `v0.1.001`
