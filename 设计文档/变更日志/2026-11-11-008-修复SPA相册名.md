# 2026-11-11-008 修复 SPA 站点相册名错误（改用渲染后的 document.title）

> 版本：**v0.2.80** ｜ 类型：缺陷修复（元数据）
> 触发：用户反馈「相册名不对 抓取是对的」

## 一、根因

相册名来自 `parseGalleryPageTitle(firstHtml, site)`，而 SPA 站点的 `firstHtml` 是空壳：

```
title: 4KHD - HD Beautiful Girls      ← 站点默认标题，不是相册名
htmlLen: 1991
```

于是解析出的相册名永远是站点默认标题。**真实相册名在渲染后的 `document.title` 里。**

图片是对的、名字是错的，正是因为图片走了 DOM 通道（正确），而标题还在读空壳 HTML（错误）。

## 二、改动

### 1. `dom-fetch.ts`：新增 `extractPageSnapshot`

```ts
extractPageSnapshot(tabId, { selector, hosts }): Promise<{ title: string; images: string[] }>
```

同一趟注入里同时取 `document.title` 和图片，不额外多一次 executeScript。
取图判据不变（正文容器 + 图床白名单）。

`extractDomImages` 保留为薄封装（只返回 images），兼容既有调用。

### 2. `dom-fetch.ts`：`extractPagesByTabNavigation`

每页结果从 `{ url, images }` 扩展为 `{ url, title, images }`。

### 3. `buondua-service.ts`

- `domFetchFn` 返回类型加 `title`
- `title` 由 `const` 改为 `let`（下方会被覆盖）
- 批量分支中，用**第一个非空** `title` 覆盖，并应用站点 `cleanTitle`：

```ts
const domTitle = pageResults.find((p) => p.title)?.title ?? ''
if (domTitle) {
  const cleaned = site.cleanTitle(domTitle)
  logger.info('buondua', '相册名取自渲染后的 document.title', { fromHtml: title, fromDom: domTitle, used: cleaned })
  title = cleaned
}
```

### 4. `background.ts`

`domFetch` 的返回类型同步加 `title`。

## 三、效果

rrwsh 的 `titleStrip` 里有 `\s*[-–—]\s*4KHD\s*$` 规则，所以：

```
document.title = "2026.10月 Fantia[9.21GB-57photos] - 4KHD"
→ cleanTitle  → "2026.10月 Fantia[9.21GB-57photos]"
```

干净相册名。同时 `BD_FETCH_ALBUM` 返回的 `name` 会用它，因此**文件夹名与文件名前缀一并修正**。

## 四、验证

- `npm run typecheck`：EXIT=0
- dist 核对（ASCII 特征）：`extractPageSnapshot` 2 处、`document.title` 6 处、`fromDom` 1 处
- `npm run build`：通过（v0.2.80）

## 五、用户实测清单

1. **刷新扩展**（v0.2.80）
2. 抓 rrwsh 相册 → 日志应出现：
   ```
   相册名取自渲染后的 document.title { fromHtml: "4KHD - HD Beautiful Girls",
                                        fromDom: "2026.10月 Fantia[9.21GB-57photos] - 4KHD",
                                        used: "2026.10月 Fantia[9.21GB-57photos]" }
   ```
3. 抓取页标题、下载文件夹名、文件名前缀都应是正确的相册名

## 六、附带收益

这个修复对**任何**开启 `domFallback` 的站点都生效 —— 以后适配新的 SPA 站点时，只要站点定义写了 `titleStrip` 清理规则，标题就会自动正确，不需要额外处理。
