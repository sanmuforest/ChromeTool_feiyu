# 2026-08-13-076 聚合搜索排除 rrwsh（4khd 反爬网关拦截）

## 背景（用户反馈）

聚合搜索结果**全部来自 rrwsh（4khd.com 链接）**，且**搜索结果正确但打开后很快被跳转到网站主页**。

## 日志解读 → 根因 → 改动点

- **根因（实测确认）**：4khd.com 相册页 `https://www.4khd.com/content/{N}/{slug}.html` 直接访问返回 **HTTP 302 → 重定向到反爬网关 `https://y5gx.uuss.uk/4khd.php`**（JS challenge），与是否带 Referer 无关（带 rrwsh Referer 同样 302）。浏览器打开后经网关验证最终跳转到 hitxhot.org 搜索页（uuss.uk 系站点同运营）——即用户看到的「打开后跳转到网站主页」
- **影响**：rrwsh 聚合搜索结果全部是 4khd.com 链接（rrwsh 为 4khd 镜像，搜索页文章链接指向 4khd.com，实测 0 个 rrwsh 域链接），因此**全部打不开**；插件后台抓取 4khd 相册同样会被 302 网关拦截
- **结论**：4khd 内容受反爬网关保护，为站点行为，插件无法绕过
- **改动点**：`gallery-sites.ts` rrwsh 配置 `searchUrl` → `null`（聚合搜索排除，同 hitxhot 先例），聚合搜索站点勾选仅剩 **jrants / pixibb**（均实测打开正常）

## 验证方式（用户实测，红线 3）

1. 重新加载 `dist/`（刷新扩展）
2. 聚合搜索：站点勾选区应只显示 **jrants / pixibb**（rrwsh、hitxhot、buondua 均不出现）
3. 搜索 → 结果应全部来自 jrants / pixibb，点击卡片可正常打开相册页（不再跳转主页）

## 回归检查（红线 1）

- 改动仅限 `gallery-sites.ts` rrwsh 的 searchUrl 配置；`parseSitePostLinks` 多 host 解析保留（rrwsh 站恢复无网关后仍可复用，只需恢复 searchUrl）
- 抓取/扫描/批量逻辑未动；tsc + build 通过
- 结论：无相邻模块受损
