# 2026-10-07-001 图站模块（FP-018）阶段 1：无行为变更重构

> 版本：**v0.2.5** ｜ 范围：多页图站适配的架构重构（不含新功能）
> 关联：`设计文档/功能规划书/FP-018-图站模块.md`

## 问题（用户提出）

多页图站经常更换域名，而现有模块不具备轻量化扩展性：

1. 换域名至少改 4 处，其中 2 处是静默陷阱 —— `searchUrl` 里写死的域名字面量（不改则搜索全失败、抓取却正常）、图床白名单 `IMG_HOST`（不改则无扩展名 CDN 图被静默丢弃）
2. 新增站点约 10 处改动、横跨 6 个文件；站点 `id` 是跨文件隐式契约（`site.id === 'jrants'` 等分支遍布 service 与 view）

## 设计（本阶段只做地基，行为不变）

- **定义即数据**：站点定义改为纯数据（无函数），可序列化 → 供后续 UI 编辑 / 导入导出 / 探测生成
- **域名单一来源**：域名只出现在定义的 `endpoints`（role: primary/mirror/search）与 `searchBaseHost`；全部 URL 由 host + 路径/参数拼装
- **id 路由 → 注册表路由**：`linkParser` / `imageCountRule` / `scan` / `throttle` / `folderTag` 定义字段 + `parsers.ts` 注册表，消除散落的 id 分支
- **命名与页序零变化**：全部站点 `folderTag='buondua'`，`ID-buondua-*` 命名与 `001-N = 抓取顺序`（2026-10-06 定稿）保持不变
