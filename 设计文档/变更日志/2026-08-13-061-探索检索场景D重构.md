# 2026-08-13-061 freeimage 场景 D 重构：探索检索（FP-007 v6/v7）

## 背景

用户修正场景 D（相册名检索）需求：
1. freeimage 探索页自带 3 模式（最新/热门/最多喜欢）× 3 类型（图片/相册/用户），检索应两组选项组合
2. 抓取阶段**只要文字信息**（相册名/地址/用户名），不加载图片，优化抓取速度
3. 需要进度条 + 终止按钮 + 流水日志窗口（加载式滚动）
4. 数据记录/合并 + 导入导出 + 关键词检索

## 实测发现（关键）

| 项目 | 结论 |
|------|------|
| 探索页 URL | `https://freeimage.host/explore/{mode}/?list={type}&sort={sort}&page=N` |
| mode→sort | recent→date_desc / popular→views_desc / trending→likes_desc |
| 分页机制 | **popular/trending 纯 page 无效（返回重复内容）**；recent 纯 page 有效；**统一方案：解析页面 next 链接（page=N&seek=游标）跟随**（与 imgbb seek 同款） |
| 相册项结构 | 无 data-name；相册名在 `list-item-desc-title-link`（如"22407081-1"），无属主字段 |
| 用户项结构 | `list-item-desc-title-link` = 用户名 + 主页 URL + 头像 |
| 抓取速度 | 仅文字 HTML 4 轮 180 条 ≈ 11.9s（每页 2~3s） |
