# 2026-10-15-005 8se.me 无斜杠入口规范化（只抓到第 1 页的根因）+ 标题实体解码

> 版本：**v0.2.39** ｜ 类型：Bug 修复（基址规范化）+ 通用修复（HTML 实体）
> 触发：用户提供两个等价入口，并指出「只抓到第一页的 18 张图」

## 一、根因：两个等价入口被当成了两种形态

用户给出：

```
https://tw.8se.me/photo/id-6ab82e0dab417.html      ← 无斜杠
https://tw.8se.me/photo/id-6ab82e0dab417/2.html    ← 有斜杠 + 页码
```

**两者指向同一相册**（多页）。而 v0.2.37 我加的 `html-auto` 判断「base 以 `.html` 结尾 = 单页相册」→ 对第一种入口 `pageUrl` **恒返回基址**，于是：

```
启用顺序翻页 { detected: 1 }
相册全子页抓取完成 { pages: 40, scanned: 72, unique: 18 }   ← 40 页全抓同一地址
```

`scanned: 72` 是同一页被解析 40 次的累加，`unique: 18` 就是第 1 页的张数 → **只抓到第一页**。

## 二、修复：把两种入口归一到同一基址

`buildBaseUrl` 的 `stripPagePath: 'html'` 分支：

```ts
let p = u.pathname.replace(/\/\d+\.html?$/i, '/')     // …/id-xxx/2.html → …/id-xxx/
if (/\.html?$/i.test(p)) p = p.replace(/\.html?$/i, '/')  // …/id-xxx.html → …/id-xxx/
```

两种入口现在都得到 `…/photo/id-xxx/`，随后 `html-auto`（base 不以 `.html` 结尾）走 `{base}N.html` 分支 → `1.html` / `2.html` / `3.html`，配合 v0.2.38 的**第一页容错**（`1.html` 失败则退回目录）即可覆盖两种首页形态。

> 该规范化仅对声明 `stripPagePath: 'html'` 的站点生效（当前仅 se8），不影响其它 10 站。

## 三、顺带修复：标题 HTML 实体未解码

日志里 `title: "瑄瑄&amp;依依 - 國模套圖 - 各國其他套圖"` —— 后台从 HTML `<title>` 取标题带实体，会直接进文件夹名（而 content script 的 `document.title` 是已解码的 `瑄瑄&依依`，两者不一致）。

`buildCleanTitle` 现在先做实体解码（`&amp; &lt; &gt; &quot; &#39; &apos; &nbsp;`）再执行 `titleStrip`。属通用修复，所有站点受益。
