# 2026-11-11-006 修正 DOM 通道取图口径（与 HTML 解析一致）+ 移除失效搜索

> 版本：**v0.2.78** ｜ 类型：缺陷修复（取图精度）+ 功能回收（移除必败通道）
> 触发：用户反馈「1 搜索慢 2 混入大量无关图片还无法剔除。相册抓取应该和其他同类型网站工作方式类似」

## 一、上一版错在哪

v0.2.76/77 的 DOM 通道直接扫描 `document.body`：

```ts
const root = document.querySelector('.entry-content, .wp-block-post-content, article, main') ?? document.body
```

问题有两个：

1. **没有使用站点定义里的正文容器**，用的是硬编码的宽松选择器列表 + 整页兜底
2. **没有应用 `imageOnlyHosts` 图床白名单**

结果：推荐位、广告、相关文章缩略图全被收进来，且无法剔除。

其他站之所以干净，是因为它们同时用了**正文容器**和**图床白名单**两道判据。DOM 通道一道都没用上。

## 二、本次改动（4 处）

### 1. `src/sites/schema.ts`：新增站点级开关

```ts
/** 启用浏览器 DOM 降级通道：服务端 HTML 是空壳的 SPA 站点专用。
 *  默认关闭 —— 只对确认是 SPA 的站点开启，避免正常站点的空页被误判而多开标签页。 */
domFallback?: boolean
```

**这是「不影响其他网站」的关键门槛**：不加这个开关时，任何站点只要某页恰好 HTML 里没有 `<img>`（比如末页），都会去开标签页抓取。加了开关后，只有显式开启的站点才会走 DOM 通道。

### 2. `src/background/dom-fetch.ts`：DOM 取图改用站点判据

```ts
extractDomImages(tabId, { selector, hosts })
```

- `selector`：由 `site.def.container` 组成（rrwsh 为 `div.entry-content`）。
  与 `containerOpen` 编译出的正则语义一致（HTML 侧是 `class="…entry-content…"`，DOM 侧是 `div.entry-content`）。
  **className 为空的站点 selector 留空 → 退化为整页，由 hosts 白名单兜底**（与 8se.me 那种「整页容器」模式一致）。
- `hosts`：`site.def.imageOnlyHosts`，按 host 精确匹配（含子域）。

`extractImagesByNavigation` 同步接收并透传这两个参数。

### 3. `src/background/buondua-service.ts`：逐页组装判据

```ts
const cls = site.def.container.className.trim()
const containerSel = cls ? `${site.def.container.tag}.${cls.split(/\s+/)[0]}` : ''
const domImgs = await domFetchFn(pageUrl, containerSel, site.def.imageOnlyHosts ?? [])
```

降级条件收紧为：

```ts
if (isSpaShell && domFetchFn && site.def.domFallback)
```

`isSpaShell` = 本页解析 0 张 **且** HTML 里连一个 `<img>` 都没有。

### 4. `src/sites/defs/rrwsh.ts`

```ts
domFallback: true,                      // 显式开启 SPA 通道
imageOnlyHosts: ['img.ssuu.uk'],        // 只认正文图床（探测样本 29 张全为该域）
// search 已移除 —— 见下
```

## 三、移除 rrwsh 的站内搜索（解决「搜索慢」）

原定义：`search: { kind: 'path-template', template: '/search/{q}' }`

站点改版成 SPA 后，**搜索结果页也是空壳**，fetch 拿不到任何结果。每次聚合搜索都会为它白跑一轮请求再失败 —— 这就是「搜索慢」的来源之一。

与其留一条必然失败的通道拖慢全局搜索，不如明确不支持：该站只保留「贴相册 URL 直接抓」。

## 六、已知取舍

| 项 | 说明 |
|----|------|
| rrwsh 无站内搜索 | 站点是 SPA，HTTP 通道必然失败；要么做 DOM 搜索通道（需探测结果页结构），要么移除。本版选择移除 |
| 多页仍慢 | 每页要开临时标签页 + 等 800ms 渲染，11 页约 20~30 秒。这是 SPA 的固有代价 |
| 容器 class 变化风险 | 若站点再改容器 class，`div.entry-content` 会失效 → 表现为「DOM 通道 0 张」。届时按真实 class 更新即可 |
