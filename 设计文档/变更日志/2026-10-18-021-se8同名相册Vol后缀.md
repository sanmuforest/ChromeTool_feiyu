# 2026-10-18-021 se8 同名相册 Vol 后缀（打包/下载命名唯一化）

> 版本：**v0.2.56** ｜ 类型：命名规则修复
> 触发：用户反馈 se8 / xchina 打包下载出现大量相同命名；提供 se8 相册页 HTML

## 一、根因

se8 的相册标题（h1）只到「一月 - PANS - 中國工作室」，**Vol 号不在 h1 里**，而在套图信息区块：

```html
<div class="item"><div class="icon"><i class="fas fa-file"></i></div>
  <div class="text">Vol. 1508</div></div>
```

`parseGalleryPageTitle()` 优先取 h1 → 文件夹名 `一月 - PANS - 中國工作室`，多个同名相册得到同一个 `folderName`：

- ZIP 名 = `${folderName}.zip` → 多个相册 ZIP 同名
- ZIP 内文件名 = `NNN-相册名.jpg` → 每个相册都从 001 开始、相册名相同 → 解压到同一目录大量覆盖

## 二、改动

### 1. 引擎新增 `titleSuffixPattern`

`src/sites/schema.ts`：

```ts
/** 标题唯一后缀：从 HTML 额外提取标识（捕获组 1），拼到标题尾部 */
titleSuffixPattern?: RegexSpec
```

`src/sites/engine.ts` 的 `parseGalleryPageTitle()`：清理标题后，若配置了该字段且标题不含后缀，则拼成 `标题 (后缀)`。

### 2. se8 配置

```ts
titleSuffixPattern: { source: 'fa-file[^>]*>\\s*</i>\\s*</div>\\s*<div class="text">([^<]+)</div>' },
```

从 `fa-file` 图标后的 `.text` 提取 `Vol. 1508`。

### 3. 效果

```
文件夹：一月 - PANS - 中國工作室 (Vol. 1508)
ZIP：   一月 - PANS - 中國工作室 (Vol. 1508).zip
文件：  001-一月 - PANS - 中國工作室 (Vol. 1508).jpg
```

不同 Vol 的相册不再同名。

## 四、用户实测清单

1. `chrome://extensions` 刷新扩展
2. 分别抓两个「一月 - PANS - 中國工作室」相册（如 Vol.1508 与 Vol.1490）
3. 检查：
   - 文件夹名是否带 `(Vol. 1508)` / `(Vol. 1490)`
   - 两次打包 ZIP 名是否不同
   - 解压后文件名是否带 Vol 后缀、不再互相覆盖
4. 若 Vol 识别失败（文件夹名仍无 Vol）：贴日志/页面 HTML 中 `fa-file` 那段，我调整正则

## 五、xchina 待处理

xchina 页面没有 se8 这样的 Vol 信息区块。需要用户提供 xchina 相册页里可用的唯一标识（Vol / 编号 / 页面内的 id），或者退而用 URL 的相册 id（`/photo/{id}`）做后缀。确认后按同机制接入。
