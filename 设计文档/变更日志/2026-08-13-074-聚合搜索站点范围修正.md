# 2026-08-13-074 聚合搜索站点范围修正（排除 hitxhot）+ 默认勾选已验证站点

## 背景（用户反馈）

聚合搜索：① 展示方式已正确（网格 6 列大封面），但**搜索结果错误、图片加载失败**；② **hitxhot 没有搜索入口**，应排除。

## 日志解读 → 根因 → 改动点

- **hitxhot 无搜索入口（用户判断正确，实测确认）**：`https://www.hitxhot.org/?s=model` 返回**站点首页**（标题 "Hit-x-Hot" + 语言选择器），`?s=` 参数被忽略。之前配置的 WP 标准 `?s=` 搜索 URL 无效 → 搜索时返回首页 → 通用解析器把首页大量导航/分类链接当结果 → **搜索结果错误**；这些垃圾链接封面全空 → **图片加载失败**。修复：`gallery-sites.ts` 的 hitxhot `searchUrl` → `null`（不再列入搜索站点勾选）
- **rrwsh 搜索路由修正**：实测 `?s=` 会 302 重定向到 `/search/{q}` → `searchUrl` 改为 `https://rrwsh.uuss.uk/search/{q}[/{page}]`
- **默认勾选范围收紧**：聚合搜索站点勾选**默认仅勾选已验证的 jrants/pixibb**（rrwsh 因站点可达性未复验，不默认勾选，可在勾选区手动选择），避免未验证站点污染结果

## 封面加载自查（红线 3）

- pixibb 搜索页 10 条结果封面 URL 全部有效（wpmedia001.pixibb.com，curl HTTP 200 / 91KB 实测）
- manifest 无 CSP 限制；imgbb 封面同机制加载正常 → 排除加载机制问题
- 结论：此前"图片加载失败"为 hitxhot 垃圾结果所致，修复后应消失

## 验证方式（用户实测，红线 3）

1. 重新加载 `dist/`（刷新扩展）
2. 聚合搜索：站点勾选区应**只显示 rrwsh / jrants / pixibb**（hitxhot、buondua 不出现），默认勾选 jrants + pixibb
3. 搜索关键词 → 结果应全部为真实相册（大封面 + 名称 + 张数），无导航/分类垃圾链接
4. 若仍出现错误结果或封面加载失败，请提供：搜索关键词、勾选站点、日志面板内容（多页图站相关 `[view]` / `[buondua]` 日志）

## 回归检查（红线 1）

- 不影响既有抓取/推荐/其他链接/批量抓取逻辑；tsc + build 通过
- 结论：无相邻模块受损
