# 2026-08-11-056 相册检索：全量返回 + 前端分页（每页 100）

## 背景

③ 区检索为纯本地数据库比对（确认时相册名已缓存，检索零网络请求、毫秒级）——批次限制（下一批结果）失去存在意义，改为**一次全量计算 + 前端分页渲染**。

## 本次改动

| 文件 | 改动 |
|------|------|
| `src/background/background.ts` | IMG_SEARCH_START 一次返回全部命中（去掉分批逻辑）；IMG_SEARCH_BATCH 保留为兼容空实现；删除 searchCandidates/searchCursor/searchKeywords 模块变量 |
| `src/grabber/view-adapters.ts` | 结果全量存内存 + 分页渲染（每页 100）：上一页/下一页/页码/命中总数；去掉「下一批结果」按钮 |

## 交互

- 关键词 + 滑条（取前 X%）+ 权重 → 点「区间检索」→ **一次出全部命中**
- 结果分页：`« 上一页 | 第 3/47 页 | 下一页 »` + `共命中 N 条`（100 条/页，几千条不卡）
- 滑条仍是**结果质量过滤**（评分前 X%），不再是性能手段

## 验证方式

1. 重新加载 `dist/` → 检索命中 >100 条的关键词 → 分页显示正常、翻页即时
2. 命中 0 时的引导提示（先确认评分）保持
