# 2026-08-10-040 图片文件名 = 序号-相册名（用户选方案 A）

## 需求

图片文件名数字后缀过长，用户选择方案 A：文件名 = `序号-相册名.扩展名`（如 `001-晨.jpeg`），完全替换原文件名。

## 实现

- `downloader.ts` `extractFilename(url, index, albumName?)`：提供 albumName 时返回 `{序号}-{相册名}.{扩展名}`（扩展名从原 URL 提取，缺失兜底 .jpg）；无 albumName 保持原截断逻辑
- `image-grab-view.ts`：`GrabViewOptions` 新增 `getAlbumName?: () => string`（默认 = 文件夹名），下载/打包共用的 `collectSelectedItems` 传入
- `buondua-parse.ts`：新增 `extractBuonduaAlbumShortName`（去 Page 标记/张数/[标签]/coser 前缀，取冒号后部分）：`Coser@年年Nnian: 晨 (80 photos)` → `晨`
- 各视图传 `getAlbumName`：
  - buondua 抓取：纯相册名（`晨`）
  - buondua 批量：每相册独立短名
  - imgbb 主页/相册：用户名/相册名
  - 主抓取页签：页面标题

## 实测

- buondua：`001-晨.jpeg` ✓
- imgbb：`002-是小桃呀.png` ✓
- 主抓取：`003-[内购无水印] 鱼子酱Fish_ 班长的礼物.jpeg` ✓

## 回归检查

- 文件夹名不变（仍为页面名）；仅文件名字段变化
- 去重/选择/预览逻辑基于 URL，不受影响
- ZIP 打包共用 collectSelectedItems，同步生效
