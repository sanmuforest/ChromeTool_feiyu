# 2026-08-10-020 修复：关注墙报错 + 相册页自动填用户名

## 问题（用户反馈 3 条）

1. 关注墙分析报错：`root.querySelector("#following-side").value` 抛 null 异常
2. 关注墙方向区分未生效（因报错中断）
3. 相册页激活未自动填入用户信息——相册页是 `ibb.co` 域名**无用户名子域**，`extractUsername` 提取不到

## 修复

1. **null 保护**：`#following-side` 获取改为可选链 + 默认 `both`，元素缺失不报错
2. **相册页用户名解析**：
   - `imgbb-parse.ts` 新增 `parseUsernameFromHtml`（从 data-object 的 user.username 或页面用户链接提取）
   - `imgbb-service.ts` 新增 `resolveUsernameFromAlbum`（fetch 相册页 HTML → 解析用户名）
   - `messages.ts` 新增 `IMG_RESOLVE_USER`（请求-响应）；background 处理
   - view-adapters 自动填充：相册页激活时异步请求用户名 → 回填用户主页 URL / 相册分析 / 关注墙
3. 自动填充改为 async IIFE（等待用户名解析后再填）

## 验证（curl 真实页面）

- 相册页 `ibb.co/album/GFHG7S` → 解析用户名 `u351622` ✓
- 相册列表页 → `u351622` ✓
