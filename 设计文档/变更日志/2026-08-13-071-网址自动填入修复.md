# 2026-08-13-071 修复多页图站网址自动填入未覆盖 jrants/pixibb

## 背景（用户反馈）

新适配的 jrants.com / pixibb.com 两个站点，在对应页面打开抓取页时，多页图站（buondua 页签）的网址输入框**没有自动填入**当前页面 URL（buondua/rrwsh/hitxhot 三个旧站点正常）。

## 日志解读 → 根因 → 改动点

- **根因**：`src/grabber/view-buondua.ts` 自动填充判断用了**硬编码正则** `/（buondua\.com|rrwsh\.uuss\.uk|hitxhot\.org）\/.*/`，新增站点未同步维护该正则
- **改动点**：改用 `matchGallerySite(sourceUrl)`（gallery-sites 配置驱动统一匹配）——与抓取/链接扫描逻辑同一来源，后续新增站点自动生效，无需再改此处的站点清单

## 验证方式（用户实测，红线 3）

1. 重新加载 `dist/`（刷新扩展）
2. 打开任意 jrants.com 文章页（如 `https://jrants.com/2026071187497.html`）→ 插件图标 → 抓取页 → **buondua 页签**：三个子标签的 URL 输入框应自动填入当前页面地址
3. 同样验证 pixibb.com 页面（如 `https://sexy.pixibb.com/otherxxx-kiy-55-photos-31-videos/`）
4. 抽查 buondua/rrwsh/hitxhot 页面，确认旧站点自动填入仍正常

## 回归检查（红线 1）

- 改动仅限 `view-buondua.ts` 自动填充一处判断；`matchGallerySite` 为既有 ACTIVE 模块函数，逻辑不变
- 日志新增 site 字段（仅信息增强，不影响功能）；tsc + build 通过
- 结论：无相邻模块受损
