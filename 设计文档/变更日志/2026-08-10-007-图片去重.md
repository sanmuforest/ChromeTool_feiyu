# 2026-08-10-007 FP-002 增强：图片去重（同图多尺寸只留最大）

## 本次改动（仅 `src/grabber/view-images.ts` + `grabber.css`）

新增「去重」开关按钮（默认开启，高亮显示）：

1. **识别同图**（URL 规范化 `normalizeKey`）：忽略 query 参数与 hash；文件名去扩展名；去掉常见尺寸/缩略图后缀（`_thumb`/`_small`/`_medium`/`_large`/`-300x200`/`-w800` 等）
2. **保留规则**：规范化后同组图片按面积（宽×高）降序，仅保留最大的一张
3. **联动**：
   - 网格/尺寸筛选/全选/默认全选 均基于去重后的列表
   - 统计栏显示「去重 N」（被移除数）
   - 切换去重开关时清理选中集合中被移除项的残留
   - 重新解析不影响开关状态（保持用户选择）

## 已知边界

- 基于 URL 启发式识别（v1），若同图 URL 结构差异大可能漏判；内容指纹（pHash）为后续可选项
- 尺寸未知的图面积按 0 计，同组多张未知尺寸时保留第一张

## 回归检查

- 下载/打包/筛选/预览逻辑未动，仅显示列表来源改为去重结果
- typecheck、build 通过
