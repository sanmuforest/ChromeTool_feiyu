# 2026-08-10-023 修复：相册属主用户名误判（parent_url 优先）

## 问题（用户日志定位）

相册 `ibb.co/album/T45x7F` 实际属主是 **u351622**，但自动填充解析成 **martin-yang**（`https://martin-yang.imgbb.com/` 错误填入）。

## 根因

`parseUsernameFromHtml` 取页面**第一个匹配的 username/用户链接**。扩展 fetch 带 Cookie 时，imgbb 返回登录态页面，开头可能出现**推荐区块**（martin-yang），导致误判属主。访客页面（curl）无此区块所以此前测试正常。

## 修复（imgbb-parse.ts 提取优先级重排）

1. **parent_url 优先**：data-object JSON 内的 `parent_url` 字段 = **相册属主主页 URL**（如 `https://u351622.imgbb.com/`），最可靠，不受登录态推荐区块干扰
2. 面包屑区域用户链接（次选）
3. data-object `user.username`（兜底）

## 验证

- 3 个相册页（T45x7F / GFHG7S / 0hL6P1）→ 均正确解析 `u351622` ✓
- 模拟登录态页面（开头含 martin-yang 推荐链接 + parent_url=u351622）→ 正确返回 `u351622` ✓
