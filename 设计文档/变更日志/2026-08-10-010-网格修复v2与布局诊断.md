# 2026-08-10-010 修复：缩略图网格压扁（v2，全 flex 链路）+ 布局诊断 debug

## 背景

009 的 `min-height: 0` 修复未生效，200 张后缩略图仍被压扁。本次根治 + 加 debug 定位。

## 本次改动

1. **布局改为全 flex 链路**（不再依赖 `height: 100%` 百分比链）：
   - `.panel.active`：`display: block` → `display: flex; flex-direction: column`
   - `.images-view`：去掉 `height: 100%`，改 `flex: 1; min-height: 0`（作为 panel 的 flex 子项）
   - `.log-panel`：`height: 100%` → `flex: 1; min-height: 0`
   - 全链路：app(100vh) → main(flex:1) → panel(flex:1) → images-view(flex:1, min-h:0) → grid(flex:1, min-h:0, overflow-y:auto)，每层显式允许收缩
2. **尺寸筛选栏限高**：`.size-filter-bar` 加 `max-height: 110px; overflow-y: auto`——防止尺寸按钮多行撑高挤压网格空间
3. **布局诊断 debug**（`reportLayout`）：
   - 解析完成时 + 窗口 resize 时自动报告各容器尺寸（app/main/panel/images-view/toolbar/size-filter/grid 及其 scrollHeight/clientHeight、首张卡片尺寸、卡片总数、viewport）
   - 日志通过 `[grabber/layout]` 输出，用户导出日志即可定位是哪层塌缩
