# 2026-10-11-008 8se.me 适配前置：CSS 背景图支持 + 四项引擎扩展

> 版本：**v0.2.33** ｜ 类型：引擎通用能力扩展（+ 探测工具三轮增强）
> 触发：适配 `tw.8se.me`（用户提供）三轮探测后定位出正文渲染方式

## 一、三轮探测的结论（8se.me）

| 轮次 | 输出 | 结论 |
|------|------|------|
| v0.2.31（宿主分组） | 只有 `tw.8se.me`(logo/菜单)、`upload.xchina.io`(固定层右栏)、`xchina.click`(固定层左栏) | 正文图床 `img.xchina.io` 缺席 |
| v0.2.32（加滚动） | 同上（滚动后仍无） | 不是懒加载未触发 |
| **v0.2.33（加 bgChains）** | `内联 background-image` 里出现 `img.xchina.io/photos/{id}/000NN_600x0.webp` 连续编号 | **正文图用 CSS `background-image` 渲染**，`<img>` 里只有站点 logo |

**URL 规则（关键）**：
- 缩略图（正文渲染用）：`https://img.xchina.io/photos/{相册id}/000NN_600x0.webp`
- **原图**：`https://img.xchina.io/photos/{相册id}/000NN.jpg`（与 `og:image` 同形态）
- 即：去掉 `_600x0` 并把扩展名改回 `.jpg`

**排除项**：`upload.xchina.io/media/*.webp` 与 `xchina.click/upload/*.webp`（落在 `z-fixed-zones` 固定层 = 推荐位）

**站点反爬**：主站与两个图床对服务端请求一律 403（带 Referer 亦无效，属 Cloudflare 类挑战）→ 该站必须走插件的**源页注入通道**（`world: 'MAIN'` 页面上下文 fetch，带 Cookie），该通道已存在且**不限域名**（2026-10-11 核实）

## 二、引擎扩展（4 项通用能力，非该站特判）

| # | 能力 | 说明 |
|---|------|------|
| 1 | **CSS 背景图解析** | `parseGalleryImages` 除 `href`/`src` 外，新增扫描 `style="…url(…)"`。此前正文用 CSS 背景的站点**必然解析 0 张**（8se.me 即此类） |
| 2 | **`imageThumbFix`** | 新增定义字段 `{ source, flags?, replace }`：按正则把缩略图 URL 还原为原图（`_600x0.webp` → `.jpg`），与既有 `imageQueryFix` 组合进 `imageUrlClean`；正则非法时保持原样（单站定义写错不影响整站） |
| 3 | **分页 `html-from-1` / `html-from-2`** | 覆盖 `{N}.html` 形态（`html-from-1` 全页含 `1.html`；`html-from-2` 第 1 页用基址） |
| 4 | **`stripPagePath: 'html'`** | 基址提取去掉尾部 `/N.html`（`.../id-xxx/2.html` → `.../id-xxx/`） |
