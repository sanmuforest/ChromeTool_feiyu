# 2026-08-11-045 hitxhot 抓取超时修复：超时提升 + 页面内 fetch 降级

## 问题（用户反馈 + 日志）

rrwsh 成功；hitxhot 失败：`[error] 全子页抓取失败 "Error: 请求超时（https://www.hitxhot.org/...html）"`（background fetch 20s 超时）。

## 根因

hitxhot.org 对**无 Cookie 的 background fetch**（扩展上下文）响应极慢/拦截（>20s），而用户浏览器页面能正常打开（页面上下文带 Cookie）。参考项目经验：buondua 等站点有反爬，**页面内 fetch（content script 带 Cookie/Referer）才能穿透**。

## 修复（两级）

1. **超时提升 + 重试**（`buondua-service.ts`）：FETCH_TIMEOUT 20s→40s，失败重试 1 次；fetch 头补 `Accept-Language` + `Referer`（同源）
2. **页面内 fetch 降级**（关键）：
   - `messages.ts`：新增 `BD_FETCH_HTML { url }`（background → content）
   - `image-scanner.ts`：处理该消息——content 页面内 `fetch(url, {credentials:'include', Referer})` 返回 HTML
   - `background.ts`：`BD_FETCH_ALBUM` 后台抓取失败 → 自动降级 content 页面内 fetch 重新全量抓取；`sendToTabAndGet` 支持响应式 tab 消息
   - `buondua-service.ts`：`fetchAlbumAllPages` 支持注入 `fetchHtmlFn`

## 验证

- 构建零警告、类型检查通过
- 逻辑：后台 40s×2 失败 → 页面内 fetch（用户已在 hitxhot 页面打开，页面上下文必可访问）
