# 2026-08-10-012 版本号徽标（右下角）

## 本次改动

1. **右下角版本号徽标**（grabber 页）：
   - `grabber.html` 新增 `<div id="version-badge">`
   - `grabber.ts` 显示 `v0.2.1 · 20260810HHMMSS`（manifest 版本 + 构建时间戳）
   - `grabber.css` 固定右下角、半透明、小字号，不遮挡内容
2. **构建时间戳注入**（`scripts/build.mjs`）：esbuild `define` 注入 `__BUILD_TIME__`（格式 yyyymmddHHMMSS，精确到秒）
   - 每次 `npm run build` 时间戳都不同，一眼确认插件是否已更新到最新构建
   - 未注入时兜底显示 `dev`

## 用途

- 用户 / pi 确认当前加载的构建版本：`chrome://extensions` 刷新后打开抓取页看右下角
- 排查"改了没生效/加载旧版"类问题

## 回归检查

- 仅 UI 展示，不影响任何逻辑；build 通过，时间戳注入验证成功
