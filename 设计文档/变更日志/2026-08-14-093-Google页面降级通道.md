# 2026-08-14-093 Google 通道重构：页面降级（标签渲染提取）替代后台 fetch

## 背景（日志定位，红线 3）

完整诊断日志证实：**新版 Google 搜索结果靠 JS 渲染**——插件后台 fetch 拿到的页面（46-67KB）为 JS 渲染壳（`hasH3: false, hasMetaRefresh: true`），`gbv=1` 已被 Google 废弃不生效；即使跟随 meta refresh 仍是壳。**后台 fetch 路线在无 JS 执行环境无法拿到新版 Google 结果**。

## 方案切换：页面降级通道

与用户手动搜索等效：**后台静默打开 Google 搜索标签（active:false）→ 真实浏览器执行 JS 渲染 → content 脚本（scripting.executeScript）等待渲染并提取结果 → 自动关闭标签**。用户保存的 450KB 渲染后页面（10 条结果）证明该通道可靠。

## 行为说明

- 搜索 Google 站点时：浏览器会短暂出现后台标签（active:false 不抢焦点），完成后自动关闭；若提取 0 条（验证页/无匹配）保留提示
- 依赖 `scripting` 权限（manifest 已有）+ `<all_urls>` 授权（搜索前 ensureHostPermission 已请求）
