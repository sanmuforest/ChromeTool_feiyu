# 2026-08-10-019 关注墙方向选项 + 新开页贴右 + 相册页自动切换场景

## 本次改动

### 1. 关注墙方向区分
- 关注墙面板新增下拉：**全部（关注+被关注）/ 仅关注中 / 仅被关注**（默认全部）
- 消息 `IMG_ANALYZE_FOLLOWING` 新增 `side` 字段；imgbb-service `fetchFollowingUsers` 按方向抓取
- 缓存按「用户名|方向」隔离（background Map），切方向后重新抓取

### 2. 新开页统一贴右
- `openTab`（相册封面/用户页跳转）改为：查询当前 grabber 页签 index → `tabs.create({ url, index: index+1 })`，**所有新开页签紧贴当前页签右侧**（与 action 创建抓取页逻辑一致）

### 3. 相册页激活自动切场景 + 补全自动填入
- 相册页激活时：自动切到 imgbb 页签「相册抓取」子标签（相册 URL 已填）
- 用户主页 URL 输入：只要识别到用户名即填入（不再要求非相册页）
- 相册分析/关注墙用户名照常填入
