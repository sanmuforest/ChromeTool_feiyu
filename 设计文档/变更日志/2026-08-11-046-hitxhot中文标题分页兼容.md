# 2026-08-11-046 hitxhot 中文标题分页兼容 + URL hash 清理

## 问题（用户反馈 + 日志）

hitxhot "能抓到但不全"。日志定位两个原因：

1. **中文标题不兼容**：hitxhot 标题有两种格式——英文 `| Page 2/3` 与中文 `| 第1/6页`（日志：`Hit-x-Hot：卷。 2193 糯美子迷你 |第1/6页`）。原 pagePattern/cleanTitle 只匹配英文 → 中文标题相册 maxPage 解析失败 → 走 page-numbers 兜底，大相册（分页导航不全）只抓部分页
2. **URL hash 未清理**：`...html#`（页面 URL 带 hash），baseUrlOf 只清了 search，导致请求带 `#` 的 URL

## 修复（gallery-sites.ts）

- hitxhot `pagePattern` 兼容中英文：`\|\s*(?:Page\s+\d+\s*\/\s*(\d+)|第\s*\d+\s*\/\s*(\d+)\s*页)`（组2 = 总页数，两分支）
- `parseGalleryMaxPage` 取 `m[1] ?? m[2]`
- hitxhot `cleanTitle` 兼容中文 `| 第N/M页` 后缀清理
- 三个站点 `baseUrlOf` 统一清 `u.hash = ''`

## 验证

- 英文标题 maxPage 3 / 中文标题 maxPage 6 ✓
- 中文标题清理 `Hit-x-Hot: 国模套图 蛊真人·商心慈` ✓
- hash 清理 `...?page=2#` → `...` ✓
- 构建零警告 ✓
