# 2026-08-13-073 聚合搜索结果展示改版（大封面网格 + 点击打开）

## 背景（用户反馈）

聚合搜索结果的展示有问题：① 点击结果卡片不能打开相册页（原卡片点击是选中/取消，无跳转）；② 封面图片没有加载（全空）。要求改版：**大封面图网格（一行 6 个），图底部显示相册名 + 图片数**。

## 日志解读 → 根因 → 改动点

- **封面全空根因**：jrants/pixibb 搜索页（与列表页同构）的封面 `img` 位于文章链接 a 的**前面**（post-thumb 块在 post-title 之前），而两个解析器只向后 3000 字符内找封面 → 封面提取全部失败。实测验证：修复后 pixibb 搜索页前 6 条封面覆盖 100%
- **点击无法打开根因**：原卡片 click 事件仅做选中切换，无跳转逻辑

## 本次改动

| 文件 | 改动 |
|------|------|
| `src/lib/jrants-parse.ts` | 封面提取改为 **a 前后 2000 字符双向搜索**（`around` 切片） |
| `src/lib/pixibb-parse.ts` | 同上（pixibb 封面正则） |
| `src/grabber/view-buondua.ts` | 搜索面板 `renderList` 改版：**大封面卡片**（3:4 封面图 + 底部相册名 + 图片数），列表容器加 `bd-search-list` class；**点击卡片任意处 → `window.open` 打开相册页**；**独立勾选框**（checkbox 左上角，stopPropagation 不触发展开）用于批量抓取选择；封面加载失败显示「无封面」占位 |
| `src/grabber/grabber.css` | 新增 `.bd-search-list`（`grid-template-columns: repeat(6, 1fr)`）+ `.bd-search-card`（hover/selected 高亮、勾选框、封面 3:4 object-fit、标题两行截断、图片数） |

- 交互约定：**点卡片 = 打开相册页**（新标签）；**点左上角勾选框 = 选中/取消**（批量抓取用）；「全选本批/抓取选中」逻辑不变
- 仅改聚合搜索面板；推荐链接/其他链接面板保持原小卡片列表（不受影响）

## 验证方式（用户实测，红线 3）

1. 重新加载 `dist/`（刷新扩展）
2. 多页图站 → 聚合搜索 → 输入关键词搜索
3. 结果应为**一行 6 个的大封面网格**，每张图底部有相册名 + 张数
4. **点击任意卡片 → 新标签打开该相册页**
5. 勾选左上角 checkbox → 抓取选中 → 批量下载正常

## 回归检查（红线 1）

- 解析器改动：封面提取从单向改双向（对文章页/相关文章解析无副作用，结果更全）
- `view-buondua.ts`：仅改搜索面板 renderList 与容器 class；推荐/其他面板、批量抓取共用逻辑（batchViews/BD_FETCH_ALBUMS）未动
- 不触碰 FROZEN 模块；tsc + build 通过
- 结论：无相邻模块受损
