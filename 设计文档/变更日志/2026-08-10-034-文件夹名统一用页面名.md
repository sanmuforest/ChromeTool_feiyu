# 2026-08-10-034 文件夹名统一改为页面名（通用修改）

## 需求

文件夹名直接使用页面名。示例：buondua 页面 `https://buondua.com/nei-gou-wu-shui-yin-...-55921` 的 h1 为 `[内购无水印] 鱼子酱Fish: 班长的礼物 (130 photos)  - ( Page 1 / 7 )`，文件夹名直接使用 `[内购无水印] 鱼子酱Fish: 班长的礼物 (130 photos)`（去掉分页标记，保留张数；冒号等非法字符清洗为下划线）。

## 改动清单（通用：所有下载类抓取）

1. **buondua 抓取 + 批量**（`view-buondua.ts` / `buondua-parse.ts`）
   - `buildBuonduaFolderName` 去掉 `ID-buondua-` 前缀与时间戳，直接返回清洗后的页面名
   - `extractBuonduaAlbumName`：保留 `(N photos)`，只去掉 ` - ( Page X / Y )` 分页标记；清洗非法字符；长度上限 60→120
2. **主抓取页签**（`background.ts`）：`buildFolderName` 去掉 `-{host}-{时间戳}` 后缀，直接用页面标题
3. **imgbb 用户主页**（`view-adapters.ts`）：文件夹名 = 用户名（页面名）
4. **imgbb 相册抓取**：文件夹名 = 相册页标题
   - `imgbb-parse.ts`：新增 `parseAlbumPageTitle`（h1 优先，`<title>` 兜底，去 ` — ImgBB` 后缀）
   - `imgbb-service.ts`：`fetchAlbumImages` 返回 `{ images, name }`
   - `messages.ts`：`MessageResponse` 增加 `name?`
   - `background.ts`：`IMG_GET_ALBUM_IMAGES` 返回相册名
   - `view-adapters.ts`：`albumFolder` 存相册标题（替换原 `imgbb-{label}-{时间戳}`）

## 验证（开发侧）

- buondua 页面名：`[内购无水印] 鱼子酱Fish_ 班长的礼物 (130 photos)` ✓
- 批量相册名：`Coser@年年Nnian_ 夏 (80 photos)` ✓
- imgbb 相册：`雪莉`（去 — ImgBB 后缀）；h1 优先 ✓
- 类型检查通过、构建零警告 ✓

## 回归检查

- 重复抓取同名页面：Chrome downloads 默认 uniquify 自动加 `(1)` 后缀，无覆盖风险
- buondua 批量多相册：各自用相册标题，天然不冲突
- 下载器/去重/预览未改
