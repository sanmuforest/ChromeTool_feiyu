按 FP-003 草案 v2 实现 imgbb 适配器（4 子标签全部手动触发）：

### 新增模块
1. **`src/lib/imgbb-parse.ts`**（纯函数解析器）：
   - `parseImageItems`：列表项 data-object JSON → 原图/展示/缩略 URL + 原图宽高 + 文件名（原图 = image.url，最大尺寸直读）

2. **`src/background/imgbb-service.ts`**：后台 fetch 编排（相册、分页抓图、相册列表、关注墙 + 逐用户相册检索，并发 6，跳过空相册用户）
3. **`src/grabber/view-adapters.ts` 重写**：imgbb 4 子标签 UI
   - 用户主页：分批（约 100/批）+ 下一批 + 分页范围 + 文件名编号范围
   - 相册抓取：URL → 全部原图
   - 相册分析：相册封面网格（点击新页打开），分页下一批
   - 关注墙：用户卡片（头像 + 相册封面行），单批 30 用户 + 下一批，跳过无相册用户
