# 2026-08-13-060 freeimage 站点适配（FP-007）编码完成

## 背景

用户调研「与 imgbb 相当的图床」（调研报告 001），选定 **freeimage.host（Chevereto 程序实例）** 作为第二个图床适配目标。FP-007 经 5 版设计确认（v5 定稿）：**先理解 imgbb 5 项子功能的真实需求，再结合 freeimage 特性实现类似功能**。

## 功能范围（5 场景，对齐 imgbb 5 项）

| 场景 | freeimage 实现 | 对齐 imgbb |
|------|---------------|-----------|
| A 用户主页抓取 | `/{user}?list=images&sort=date_desc&page=N&ajax=1` | ① 用户主页 |
| B 相册抓取 | `/a/{slug}.{ID}` 首屏 + AJAX 翻页全量 | ② 单相册 |
| C 相册分析 | `/{user}/albums?sort=&page=N` → 相册卡片 | ③ 快速检索相册 |
| D 相册名检索 | 探索页采集 → 属主 → 相册名索引 → 关键词过滤 → 跳转 | ④ 变体搜索 |
| E 类群鉴别 | 多轮手动扩散 → 候选 → 标注（目标/排除）→ 类群库 → 导出 | ⑤ 强化搜索 |
