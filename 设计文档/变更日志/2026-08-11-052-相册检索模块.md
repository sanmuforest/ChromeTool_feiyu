# 2026-08-11-052 相册检索模块：确认评分 + 百分比区间 + 关键词匹配（FP-005 第二阶段）

## 概述

FP-005「关注链扩散检索」第二阶段完成：**相册检索**。UI 为扩散检索子标签新增第 3 区域「③ 相册检索」。

## 核心设计：确认时缓存相册名 → 检索纯本地零请求

- **确认评分（有请求）**：对未确认候选（按入度降序）抓 albums 页 → 相册数 + **相册名列表缓存入库**（albumsChecked/albumCount/albums 字段）
- **区间检索（零请求）**：已确认用户按综合评分排序 → 百分比区间（0~100 可配）→ 关键词**本地匹配**缓存相册名 → 命中列表
- 昂贵操作（albums 请求）只做一次、重复利用；检索本身不再消耗任何 imgbb 请求

## 使用流程

1. 扩散积累生产者库（①②区）→ 合并入库
2. ③ 区「确认评分」逐批补相册（有相册 N / 零相册 M / 失败 F / 剩余未确认）
3. 填关键词（逗号分隔）+ 百分比区间（默认 0~100）+ 入度权重（默认 60%）→「区间检索」
4. 命中列表：用户名（打开主页）+ 命中相册（打开相册页），「下一批结果」继续

## 已知边界

- 检索候选为**内存态**（searchCandidates），SW 重启后需重新「区间检索」
- 区间基于**已确认且有相册**的用户（零相册用户不参与）
- 关键词 OR 匹配（任一命中即列出该用户所有命中相册）

## 验证方式

1. 重新加载 `dist/` → 扩散几批 → 合并入库
2. 「确认评分」几批 → 观察有相册/零相册比例
3. 填关键词（如「龙珠」）+ 区间 0~100 → 区间检索 → 命中列表出现用户与相册，点击可打开
4. 调区间（如 0~10）→ 只检索最高分档
