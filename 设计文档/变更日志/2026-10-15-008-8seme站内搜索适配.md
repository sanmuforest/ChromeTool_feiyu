# 2026-10-15-008 8se.me 站内搜索适配 + 搜索分页新增 pageBase

> 版本：**v0.2.42** ｜ 类型：新增站点能力（搜索）+ 引擎修复（页码式分页）
> 触发：用户提供站内搜索入口 `https://tw.8se.me/search.html?keyword={q}`

## 一、站内搜索适配

| 项 | 配置 |
|----|------|
| `search` | `{ kind: 'query', path: '/search.html', param: 'keyword', pageParam: 'page', pageStep: 1, pageBase: 1 }` |
| `searchAlbumPattern` | `^/photo/id-[0-9a-f]+(?:\.html|/\d+\.html)?/?$` —— 只保留相册页 |
| `endpoints` | primary 由裸域 `8se.me` 改为 **`tw.8se.me`**（实测可用域；搜索 URL 由 primary 生成，必须指向它），裸域作 mirror |
| `channels` | `google` → **`site`**；UI 中 se8 由 Google 组移入站内搜索组 |

**离线核对**：第 1 页 URL 与用户给出的**完全一致**（`https://tw.8se.me/search.html?keyword=%E7%A7%81%E8%B4%AD%E6%B5%81%E5%87%BA`）。

**过滤正则自测**：两种相册形态（`/photo/id-xxx.html`、`/photo/id-xxx/2.html`）与目录形态均 PASS；`/photos/series-*.html`、`/search.html` 均 fail（正确排除）。

## 二、引擎修复：搜索分页缺「页码式」表达

原 `query` 分页只有**偏移量语义**：

```ts
(page - 1) * (search.pageStep ?? 10)     // 第 2 页 → &page=1（页码式站点会重复请求第 1 页）
```

对页码式站点（`&page=2`）无法表达。**新增可选 `pageBase`**：

```ts
const value = (page - 1) * (search.pageStep ?? 10) + (search.pageBase ?? 0)
```

- 默认 `0` → 偏移量式站点（buondua 的 `&start=0,20,40`）**行为完全不变**（已回归核对）
- se8 配 `pageStep: 1, pageBase: 1` → 第 2 页得到 `&page=2` ✓

## 四、用户实测清单

1. 刷新扩展 → 多页图站 → 聚合搜索
2. **se8 现在位于「站内搜索」组**（此前在 Google 组）
3. 勾选 se8 → 搜一个词（如「私购流出」）→ 预期返回相册卡片
4. 点「下一批（继续检索）」→ 应返回第 2 页
   - **若第 2 页内容与第 1 页相同** → 说明该站分页参数名或语义与假设不符，请把浏览器地址栏里第 2 页的真实 URL 发我（改定义一行即可）
5. 点开结果抓取 → 抓取正常；**下载请用「下载选中」**（该站图床 CORS 限制，打包不可用，详见 2026-10-15-007）
