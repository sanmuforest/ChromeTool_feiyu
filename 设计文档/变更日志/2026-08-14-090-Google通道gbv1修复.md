# 2026-08-14-090 聚合搜索 Google 通道修复：gbv=1 基础版 + 双模式解析 + 诊断增强

## 背景（用户日志定位）

用户日志（v0.1.7）：
```
[warn] Google 搜索无结果 { site: kaizty }
[info] 聚合搜索完成 { merged: 0, query: "cos", sites: 1 }
```

## 日志解读 → 根因 → 改动点

- **解读**：fetch 未报网络错误（走到了「解析 0 条」分支）→ Google 返回了页面，但无可解析结果
- **根因**：新版 Google 搜索结果**靠 JS 渲染**——用户手动保存的 HTML（450KB）是浏览器执行 JS 后的 DOM；而插件 fetch 拿到的是**服务端初始 HTML（无 h3/zReHs 结果）**→ 解析 0 条
- **改动点**：
  1. 搜索 URL 加 **`&gbv=1`**（Google 官方无 JS 基础 HTML 版，服务端直接渲染结果，结构 `h3.r > a[href]` 直链）
  2. `parseGoogleResults` **双模式**：现代 zReHs（渲染后 DOM）+ 基础版 h3.r（gbv=1 服务端）
  3. **测试按钮诊断增强**：返回页特征（大小/标题/是否含 h3 结果/是否同意页）显示在状态行——再遇到无结果可直接看原因
