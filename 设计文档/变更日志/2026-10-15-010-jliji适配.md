## 一、探测结论（用户浏览器内探测，点开大图后执行）

| 项 | 实测结果 |
|----|---------|
| 站点 | `www.jliji.com`（聚丽集），**不需要登录** |
| 相册 URL | `/set/{id}`，**单页无分页**；`?lang=zh` 为语言参数（可省略） |
| 正文容器 | **`div.gallery-grid`**（其下 `div.gallery-item.progressive-image`） |
| 张数 | `gallery-item` **110 个**，与标题「110P」精确吻合 |
| 图床 | `cdn.jliji.com/galleries/8se/{hash}/…`（与 8se.me 同源内容） |
| **缩略图** | `<img src>` → `…/thumbs/N.webp` |
| **原图** | **`<img data-full>`** ← 关键发现 |
| 标题 | `{相册名} - {模特} - 聚丽集`（站名在尾部） |
| 搜索 | `/images/search?q={q}`（无分页） |

**关键点**：`img` 上的属性名探测输出为 `src, data-full, data-expected-thumb, data-image-id, …` —— 真图在 `data-full`，而引擎原先只扫 `href` / `src` / CSS `url()`，**会抓到缩略图**。

## 二、引擎新增能力：`imageAttr`

站点定义可声明「图片 URL 所在属性」：

```ts
imageAttr: 'data-full'      // 声明后引擎只扫该属性，不扫 href/src/style
```

- 属**通用能力**：任何「真图在 `data-*`、`src` 是缩略图」的站都能用
- 未声明的站点走原路径（`href` / `src` / CSS 背景），行为零变化

## 三、站点定义（`src/sites/defs/jliji.ts`）

- 相对路径 ✓（引擎支持）
