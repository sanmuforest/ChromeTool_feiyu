# 2026-10-17-015 xchina.co 站内搜索接入（小黄书 xChina）

> 版本：**v0.2.49** ｜ 类型：站点能力补全（站内搜索）
> 触发：用户提供搜索页 `https://xchina.co/search?q=xc` 与「探测结构」输出

## 一、改动前状态

xchina 定义里 `channels: ['google']`，站内搜索标注「待确认（暂 Google）」——即聚合搜索只能走 Google 站内搜索通道，受 Google 限频约束（4 秒间隔、每轮 8 次、被拒冷却 15 分钟）。

## 二、探测结论（用户浏览器内「探测结构」）

```
标题: xc - 站内搜索 - 小黄书 xChina
URL:  https://xchina.co/search?q=xc
分页(0): （无）
正文结果图床: img.xchina.io/photos2/{id}/…_600x0.webp
  父级链: span.ph.aspect-[3/4] < a.group.block < div.grid… < section.mb-8 < main.py-4
侧边栏推荐: upload.xchina.io ×25 / xchina.click ×7
视频结果: r2.xchina.download ×8（span.ph.aspect-video）
广告: z6v2p9a8.bkcdn.net ×1
```

关键判断：

1. 搜索页是 `/search?q={q}`，**没有分页链接**（探测分页数 0）→ 用 `path-template` 只取第 1 页，避免对同一 URL 重复请求。
2. 结果卡片链接为角标形式，预测为 `/photo/{id}`；侧边栏推荐与视频结果为噪声 → 用 `searchAlbumPath: '/photo/'` 收窄。
3. 结果正文图床与相册页同源（img.xchina.io），但路径为 `photos2/`；相册页解析不受影响（搜索结果只取链接，进入相册后按相册页规则解析）。

## 三、改动

### 1. `src/sites/defs/xchina.ts`

```ts
channels: ['site'],                                   // 原 ['google']
search: { kind: 'path-template', template: '/search?q={q}' },
searchAlbumPath: '/photo/',
```

- 用 `path-template` 而非 `query`：探测确认无分页；`query` 型在 `pageParam` 缺省时会把同一 URL 重复请求 N 次。
- `searchAlbumPath` 用于过滤侧边栏推荐与视频结果，只保留相册链接。

### 2. `src/grabber/view-buondua.ts`

- `googleGroupIds` 移除 `'xchina'`（Google 组减少 1 项）
- 站内组 `renderGroup([...])` 增加 `'xchina'`

两处必须一致（站点适配总览第五节第 4 条）。

## 五、用户实测清单

1. `npm run build` 已完成 → `chrome://extensions` 刷新扩展（**必须刷新，否则旧后台仍在运行**）
2. 打开插件 →「多页图站」→「聚合搜索」
3. xchina 应出现在「站内搜索」组（不再带「（Google）」标记），勾选后搜索一个关键词
4. 看日志面板：
   - 正常：`聚合搜索完成`，xchina 有条目、无 `Google 通道` 相关日志
   - 若出现 `站点搜索被反爬拦截` 或结果恒为 0：说明 **Cloudflare 拦截了扩展后台 fetch**（探测走浏览器 DOM，后台 fetch 走扩展网络栈，两者不等价）
5. 点一条 xchina 结果 → 确认能打开相册页并正常抓取

## 六、实测结论（2026-10-17）

用户确认：**站内搜索可用**，能搜到 xchina 结果。

同轮实测还发现另一个独立缺陷：相册多页抓取只抓第 1 页 30 张（见 `2026-10-17-016`），与本变更无关。

## 七、风险与回退

- **Cloudflare 未验证**：xchina 主站对服务端请求 403（变更日志 014 已记录）。站内搜索能否成功取决于扩展后台 fetch 是否被 CF 放行。若实测被拦：
  - 回退方案：把 `channels` 改回 `['google']`、移除 `search`/`searchAlbumPath`，并在站点适配总览中把结论写成「CF 拦截后台 fetch，站内搜索不可用，维持 Google 通道」。
  - 回退需另开一次改动与变更日志，不在本轮内做。
