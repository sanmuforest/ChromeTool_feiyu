# 2026-08-13-064 中文相册高效筛选（FP-007 v9）

## 背景

用户反馈：freeimage 探索检索运转良好，但中文用户稀少，检索信息大多无用，需要高效筛选中文相册的方式。

## 实测关键

| 数据点 | 结论 |
|--------|------|
| 热门流中文占比 | 0/36（0%） |
| 最新流中文占比 | 2/36（~5%，种子稀疏但存在） |
| 中文用户社交网络 | jzqgoodlife 关注/粉丝均 0（关注链对中文用户无效） |
| **属主深挖放大** | 种子「夜间疗愈剂美化」→ 属主 sservaro（9 相册 6 中文）；「金丝雀」→ fffarara（7 相册 6 中文） |

## 方案：中文种子 → 属主深挖 递归扩散

```
探索采集 → 识别中文相册（含 CJK，~5%）→ 属主提取（相册页 user-link）→ 属主全部相册（66%+ 中文）→ 入索引 → 新种子递归
```

## 本次改动

| 文件 | 改动 |
|------|------|
| `src/lib/freeimage-parse.ts` | +`isChineseAlbum`（CJK 判断纯函数） |
| `src/lib/freeimage-types.ts` | `FhAlbumIndexEntry` +`mined`（深挖标记） |
| `src/lib/messages.ts` | `FH_EXPLORE_SEARCH_START/NEXT` +`chineseOnly`；+`FH_EXPLORE_MINE`；`FhResultKind` +'explore-mine' |
| `src/background/background.ts` | `runSearchBatch` +`chineseOnly`（非中文跳过）；+`FH_EXPLORE_MINE` 分支（种子→属主→属主相册递归，mined 去重） |
| `src/grabber/view-freeimage.ts` | 探索检索加「仅中文」开关 +「中文深挖」按钮（轮数可设）+ 记录库中文统计 + onResult 'explore-mine' 分支 |

## 实测验证（node 端到端，真实页面）

- 探索采集 2 页 72 相册 → 4 中文种子（夜间疗愈剂美化/私密相册×2/金丝雀）✅
- 深挖第 1 轮：sservaro（9 相册 5 中文）+ fffarara（7 相册 6 中文）→ +11 中文相册 ✅
- 递归去重：后续轮同属主相册 0 新增（mined 标记防重复）✅
- 中文占比：探索流 5% → 索引 17%（2 页探索 + 2 属主，随轮次继续增长）✅
- tsc + 构建通过

## 使用方式

1. 探索检索：勾选「仅中文相册」→ 开始检索（自动过滤非中文）
2. 点「中文深挖」（轮数可设）→ 种子→属主→属主中文相册递归入索引
3. 记录库统计显示「共 N 条（中文 M 条）」
4. 关键词检索（本地匹配，命中率大幅提升）
