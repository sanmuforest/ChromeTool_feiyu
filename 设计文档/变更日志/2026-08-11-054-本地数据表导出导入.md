# 2026-08-11-054 本地数据表导出/导入（替代 GitHub 同步）

## 背景

GitHub 同步推送失败（HTTP 404：token 无权访问或仓库不可见），用户决定不使用 GitHub 保存，改为**本地 JSON 文件导出/导入**。

## 本次改动

| 文件 | 改动 |
|------|------|
| `src/lib/messages.ts` | IMG_DB_EXPORT / IMG_DB_IMPORT；MessageResponse +json |
| `src/background/background.ts` | EXPORT（返回 JSON 文本）；IMPORT（loadDb 校验 → mergeDb 合并 → 持久化，返回前后数量） |
| `src/grabber/view-adapters.ts` | ④ 区由 GitHub 改为「本地数据表」：导出数据表 / 导入合并 + 隐藏 file input |

## 使用方式

- **导出**：点击「导出数据表」→ 下载 `imgbb-producers.json`（默认到下载目录）→ 可移动到本工程目录保存（如 `数据表/imgbb-producers.json`）
- **导入**：点击「导入合并」→ 选择工程内 JSON → 解析校验 → **入度累加合并**入库（`mergeDb`，多份文件可重复合并，不丢数据）

## 保留/移除

- GitHub 代码（`src/lib/github-sync.ts` + background 分支）**保留备用**，UI 入口移除；模块边界标注 PLANNED
- 本地导出/导入不依赖任何外部服务与权限（chrome.downloads + file input）

## 验证方式

1. 重新加载 `dist/` → ② 区读取库 → ④ 区「导出数据表」→ 下载 JSON（含中文相册名不乱码）
2. 清空库 → 「导入合并」选择导出的文件 → 库恢复（前后数量一致）
3. 多份文件重复导入 → 入度累加

## 回归检查

- 导出 JSON 结构 = ProducerDb（version/updatedAt/entries），loadDb 校验容错
- 导入仅合并不覆盖（mergeDb 语义），清空需手动操作
