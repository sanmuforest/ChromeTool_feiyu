# 2026-10-17-020 新站适配：xiuren.org（秀人网 XiuRen）+ 引擎新增 imagePathPattern

> 版本：**v0.2.54** ｜ 类型：新增站点 + 引擎小扩展
> 触发：用户提供相册页 `http://www.xiuren.org/ru1mm-259.html` 与页面 HTML

## 一、站点结论（用户提供的 HTML 实测）

- 相册：`/ru1mm-259.html`，**单页 42P**，无分页
- 正文容器：`div.post`（页面唯一；`id="post"` 不是 class，不会误匹配）
- 每张图：`<span class="photoThum"><a href="原图"><img src="缩略图" width=… height=…></a></span>`
- 缩略图：`/ru1mm/259/Thum/Thum-ru1mm-259-001.jpg`
- 原图：`/ru1mm/259/ru1mm-259-001.jpg`（实测 1800×1200 或 1200×1800）
- 标题：`[RU1MM_如壹写真] No.259 小鲜肉NUNU无内肉丝美臀套图 42P - 秀人网 XiuRen.org`

## 二、发现的通用问题：同域噪声图

`div.post` 里除了 42 张缩略图，还有：

- `images/2015/03/2001236775.jpg`（首图，alt 为 `ru1mm-259-037.jpg`）
- `img/download_all.gif`（下载按钮）

仅靠 `imageOnlyHosts`（同域 `www.xiuren.org`）无法剔除，会把它们当正文图收进来。

### 新增引擎能力：`imagePathPattern`

`src/sites/schema.ts` + `src/sites/engine.ts`：

```ts
/** 图片路径过滤：只保留 pathname 匹配该正则的图片 */
imagePathPattern?: RegexSpec
```

`collect()` 在域名过滤之后按 `pathname` 再过滤一层；不配置时行为不变（其余 12 站零影响）。

xiuren 配置 `{ source: '/Thum/Thum-' }` → 只保留 42 张缩略图，再由 `imageThumbFix` 还原为原图；`thumbUrl` 机制（v0.2.51）让网格显示缩略图、下载走原图。

## 五、用户实测清单

1. `chrome://extensions` 刷新扩展
2. 打开 `http://www.xiuren.org/ru1mm-259.html` → 插件 →「多页图站」
3. 抓取该相册，预期：**42 张**，日志 `unique: 42`
4. 尺寸应显示 `1800×1200` 或 `1200×1800`（异步探测原图）
5. **下载一张确认是原图**（不是 `Thum/Thum-` 缩略图）
6. 若网格大量加载失败：该站为 **http**，扩展页 `<img>` 可能被混合内容策略拦截；看日志是否走 `图片兜底取字节`，把日志贴我

## 六、已知风险

- 站点为 http，扩展页加载 http 图片可能被 Chrome 混合内容策略阻止；若如此，需改用 blob 兜底或提示用户。
- 未配置搜索通道（xiuren 无站内搜索）；聚合搜索中该站会提示不支持搜索。
