## 1. 确认评分增强

| 改动 | 说明 |
|------|------|
| 排序选项 | 入度优先（默认）/ 最新优先 / **评分优先**（未确认用户无相册数，评分仅入度项 ≈ 入度优先，UI 如实标注） |

## 2. GitHub 跨平台同步（手动触发，非实时）

新模块 `src/lib/github-sync.ts`（PLANNED → ACTIVE）：

- 单文件 `imgbb-producers.json`，Contents API 读写（PUT/GET），UTF-8 base64 安全编解码（相册名含中文）
- **推送**：先 GET 远程 sha → PUT 覆盖（409 冲突提示先拉取）
- **拉取**：GET → `mergeDb` 入度累加合并 → 本地持久化（冲突不丢数据）
- 认证：Fine-grained PAT（仅仓库 contents 读写），token 存本地 `github_config`

### 消息协议（新增）

| type | 说明 |
|------|------|
| `IMG_GITHUB_GET_CONFIG` / `IMG_GITHUB_SAVE_CONFIG` | 配置读取/保存（repo/token/branch） |
| `IMG_GITHUB_PUSH` | 推送本地库（覆盖远程） |
| `IMG_GITHUB_PULL` | 拉取远程并合并入本地 |

### UI（④ 区）

仓库 + token（password 输入）+ 保存配置 / 推送 / 拉取合并 + 配置状态显示；初始化回填已保存配置。
