## 2. 关键结论

1. **图床层没有「用户 + 相册 + 关注」生态**：所有反查到的图床（自建 CDN 集群 / WordPress Photon / box 系第三方图床 / Google 图床）都只是存储，不能作为扩散检索入口。
2. **图床价值 = 直链可下载**：`reiobox.top/wp-content/uploads/...webp` 实测 200，可匿名直连。
3. **同运营方多域名是常态**，单域名白名单会漏抓：
   - `ilovexs`：一个相册 170 张图分布在 `reiobox.top`(158) / `karubox.top` / `fujibox.top` / `nekobox.top` / `quenbox.top` / `rakuda.my.id`，而 `imageHosts` 只配了 `ilovexs.com`
   - `buondua`：`i2 / cdn / i / i0.buondua.com` 四子域 + `2.bp.blogspot.com` 外链
   - `misskon`：`kul.misskon.com` + 主域
   - `jrants`：`jrants.com` + `m2.jrants.com`
   - `xchina` / `se8`：共用 `upload.xchina.io`（同一运营方）
   - `hitxhot` / `phimvuspot` / `rrwsh`：共用 WordPress Photon（`i*.wp.com`）
4. **站点状态变化**：`kaizty`、`xiuren` 在代理下仍 000（站点本身不可用，非网络问题）。
