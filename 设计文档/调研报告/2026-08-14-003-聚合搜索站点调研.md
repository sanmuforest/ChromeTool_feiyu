## 分站实测细节

### jrants.com（`?s=` WP 标准）
- 浏览器 `?s=cosplay` → 标题 "Search Results for "cosplay" – 青年美圖"，**30 条 `.html` 结果**
- 结果示例：`/2026081193583.html` — `[Cosplay] elf (31P)`
- 标题张数标记：`(31P)`、`[100P]`、`(61P)`、`(78P)` 等
- curl 直连 HTTP 000（此前 2026-08-13 记录"连续搜索触发 Search Request Blocked"）→ 判断为**限流/指纹拦截**，需请求间隔；浏览器（真实指纹）正常

### sexy.pixibb.com（`?s=` WP 标准）
- curl `?s=cosplay` → 200，151KB，标题 "You searched for cosplay | PixiBB"
- 结果链接：`/er-81-photos/`、`/jp-rina-koike-124-photos/`、`/nice-amp-yunx1x1-amp-100-photos-1-video/`
- **slug 尾部 `NNN-photos` 即张数**（81/124/100）
- 结果页与列表页同构（历史 073 已修封面提取），解析器可复用

### rrwsh.uuss.uk（4khd 镜像，`/search/{q}`）
- curl `/search/test` → 200，73KB，标题 "search- test - 4KHD"
- 结果链接**全部指向 `www.4khd.com/content/{N}/{slug}.html`**（搜索页 0 个 rrwsh 域链接）
- 封面：`i0.wp.com/pic.4khd.com/...`（可达）
- 标题格式：`Bimilstory Min (민) Vol.05 Physical Test[506MB-126photos]` → `[NNNphotos]` 即张数
- **关键突破**：`4khd.com/content/...` 仍被反爬网关 302（→ y5gx.uuss.uk/4khd.php），但**同一路径在 `rrwsh.uuss.uk` 域下直接可达**（200，84KB，无重定向）：
  - `rrwsh.uuss.uk/content/06/bimilstory-min-vol05-physical-test.html` ✅
  - 分页 `.../html/2` ✅（标题 "Page 2 of 7"，匹配现有 pagePattern）
  → 适配：搜索解析时把结果 URL host 改写为 `rrwsh.uuss.uk` 即可全链路可用

### hitxhot.org / kaizty.com（Google 通道）
- `?s=` 均返回首页（无站内搜索，确认 074 结论）
- **官方搜索表单 action = `https://www.google.com/search`**，参数 `q` + 隐藏 `sitesearch=www.xxx.com`（用户所述"使用谷歌搜索"）
- Google 直接请求（无头浏览器）→ `google.com/sorry/index` 验证页（反爬）；真实用户浏览器（有 cookie）正常
- Google 结果页：链接为 `/url?q={真实URL}` 重定向形式；无缩略图（网页搜索）

### buondua.com / imgbb
- buondua：浏览器 open 超时（90s），站点不可达（与历史一致）→ 排除
- imgbb：首页无搜索表单/搜索链接（纯图床）→ 无站内搜索

## 适配架构（草案）

1. **后台 fetch 组**（jrants / pixibb / rrwsh）：直接 fetch 搜索页解析，沿用 BD_SEARCH 链路
   - jrants：请求间隔 ≥2s（防限流）；错误提示"限流请稍后重试"
   - pixibb：slug 提取张数
   - rrwsh：结果 URL host 改写 `4khd.com` → `rrwsh.uuss.uk`；标题 `[NNNphotos]` 提取张数
2. **Google 页面降级通道组**（hitxhot / kaizty）：点击搜索后自动开 Google 搜索标签 → content script（activeTab）解析结果页 → 回传聚合列表；封面缺失显示站点占位
3. **排除组**：buondua（不可达）、imgbb（无搜索，待用户确认是否也走 Google 通道）
