# FP-006 标签云（草案，待确认）

## 需求

基于生产者库缓存相册名，统计生成**标签云**：演员名 / 服装 / 主题 / 品牌分类展示，点击标签自动进行相册匹配检索。纯本地、零网络请求。

## 核心方案（预研已验证）

- **统计点 = 相册数**（标签出现在多少个相册名）
- **过滤**：相册数 ≥10 且 覆盖用户数 ≥2（剔除铁粉灌水）
- **排序**：相册数降序，Top N 可调（默认 100）
- **分类**：演员（日文/中文名整段）/ 服装 / 主题 / 品牌 / 英文（含中文注释）

### 标签提取规则（tag-extract.ts，纯逻辑）

```
① 清理 emoji/符号
② @引用 → 独立标签
③ 品牌剥离（前缀优先）：tokyo hot / pornbox / jav / ugirls / 秀人网 ...
④ 编号剥离：E\d{2,4} / -数字 / 纯数字
⑤ 分段：逗号/&/括号 → 多名字
⑥ 名字提取（多语言，预研验证）：
   - 中文/日文：汉字+假名连续段整段（杨晨晨 / 永瀬ゆい / 神楽坂真冬）
   - 韩语：谚文连续段（예하 / 정미 / 손예은，分类 korean）
   - 英文：Capitalized 词序列合并（emily willis / miyuki matsui）
⑦ 主题词整段命中（蕾姆/原神/碧蓝航线...）→ 主题
⑧ 服装词：中文包含匹配 + 英文独立词匹配（ol/jk/lolita/latex/cosplay/t，防字母误匹配）
⑨ 停用词过滤（Model/写真/杂图/sexy/月份缩写/韩语通用词...）
⑩ 拼音→中文合并（wang yu chun → 王雨纯）
⑪ 非中文标签附中文注释（词典 + 兜底）
```

- 分类：japanese 演员 / korean 韩语 / theme 主题 / clothes 服装 / brand 品牌 / english 英文 / at 引用（七色区分）

## 数据流

```
producerDb.entries[].albums[].name（已缓存）
  → 标签提取 + 统计（相册数/覆盖用户数）
  → 过滤（≥10 相册 & ≥2 用户）
  → 排序 Top N → 标签云 UI
点击标签 → 关键词=标签 → 复用 IMG_SEARCH_START 检索（includes 匹配，零请求）
```

## 消息协议

| type | 说明 |
|------|------|
| `IMG_TAG_GET`（topN 可调） | 返回标签列表 [{ t, c, albums, users }] |

## UI（② 区新增「标签云」区块）

- 标签云：字号按相册数、颜色按分类（演员蓝/服装粉/主题绿/品牌橙/英文灰）
- 分类图例 + Top N 输入（默认 100）
- **点击标签 → 自动填入③区关键词并触发检索**，结果显示在③区（滚动定位）

## 类型与模块

- 新模块：`src/lib/tag-extract.ts`（标签提取/服装词/停用词/注释词典，纯逻辑）
- 修改：`messages.ts`（IMG_TAG_GET）、`background.ts`（统计分支）、`view-adapters.ts`（②区标签云 UI，需解锁 FROZEN）
- `producer-db.ts` / `imgbb-diffuse.ts` **零改动**（数据只读）

## 性能

- 32501 相册 × 提取正则 ≈ 实时计算毫秒级（每次 IMG_TAG_GET 现算）
- 若后续库超 10 万相册，可加缓存（库变更时置脏）——当前不需要

## 配置

- Top N（10~500，默认 100）
- 过滤阈值固定（相册≥10 且 用户≥2），可后续放开

## 开发顺序

1. `tag-extract.ts` 纯逻辑（迁移预研脚本规则）
2. `IMG_TAG_GET` 统计分支
3. ②区标签云 UI + 点击检索联动
