# FP-012 聚合搜索重构：全站适配 + 统一结果

> 状态：**已实现（2026-08-14，变更日志 083）**
> 关联：FP-010（原聚合搜索，UI 已禁用）、调研报告 2026-08-14-003
> 目标：聚合搜索真正可用——逐站适配搜索流程，统一展示「封面图 + 相册名 + 张数 + 点击跳转」，复用批量抓取链路
> **本期范围（用户确认）**：后台 fetch 三站（jrants/pixibb/rrwsh）+ 站点徽标；Google 通道（hitxhot/kaizty）与 imgbb 留待后续迭代

## 一、现状与问题

- FP-010 聚合搜索因站点反爬/无搜索入口被禁用（变更日志 077）：jrants 限流、pixibb 不稳定、rrwsh 结果打不开（4khd 网关）、hitxhot/kaizty 无站内搜索、buondua 不可达
- 2026-08-14 全站实测（调研报告 003）后，多数问题已找到解法

## 二、站点适配方案（调研结论）

| 站点 | 方案 | 关键实现 |
|------|------|---------|
| jrants | 后台 fetch `?s=`（恢复） | 请求间隔 ≥2s 防限流；标题 `(NNNP)`/`[NNNP]` 提取张数 |
| pixibb | 后台 fetch `?s=`（恢复） | slug `NNN-photos` 提取张数 |
| rrwsh | 后台 fetch `/search/{q}`（恢复） | 结果 URL host 改写 `4khd.com`→`rrwsh.uuss.uk`（绕过网关）；标题 `[NNNphotos]` 提取张数 |
| hitxhot | **Google 页面降级通道** | 自动开 `google.com/search?q=&sitesearch=hitxhot.org` 标签 → content script 解析结果 → 回传 |
| kaizty | 同上（sitesearch=kaizty.com） | 同上 |
| buondua | 排除（站点不可达） | 不列入站点勾选 |
| imgbb | 待定（无站内搜索；可走 Google 通道或排除） | 用户确认 |

## 三、Google 页面降级通道设计（hitxhot/kaizty）

1. 用户勾选含 Google 通道站点点击搜索时：
   - 后台先执行后台 fetch 组（jrants/pixibb/rrwsh）
   - 对 Google 通道站点：`chrome.tabs.create` 打开 `https://www.google.com/search?q={关键词}&sitesearch={域名}` 新标签
2. content script（activeTab 动态注入 google.com）：
   - 解析结果：`a[href^="/url?q="]` → URL 解码取真实链接 → 过滤目标域（hitxhot.org/kaizty.com 的相册链接）
   - 标题：链接文本
   - 封面：Google 网页搜索无缩略图 → 显示站点占位图（首次抓取该相册后显示真实封面）
   - 结果经 background 转发回 grabber（复用 BD_RESULT search-site 消息）
3. 反爬处理：若 Google 返回 sorry 验证页 → content script 检测到并提示用户完成验证后点「重试导入」
4. 自动关闭已处理的 Google 标签（或保留供用户浏览，待定）

## 四、统一结果模型与展示

- 结果类型不变：`BuonduaLinkItem`（url / title / coverUrl / imageCount）
- 展示（现有 UI 复用）：大封面网格（一行 6 个）→ 封面图 + 相册名 + 张数；**点卡片新标签打开相册页**；勾选框批量抓取
- 张数增强：三个后台 fetch 站点均可提取真实张数（jrants 标题 / pixibb slug / rrwsh 标题）；Google 通道站点张数未知 → 显示「张数未知」
- 站点标识：每张卡片显示来源站点（badge），便于识别

## 六、消息协议（新增登记）

| type | 发起方 | 处理方 | 说明 |
|------|--------|--------|------|
| `BD_GOOGLE_OPEN` | grabber | background | 打开 Google 搜索标签（sitesearch 站点） |
| `BD_GOOGLE_RESULT` | content | background | Google 结果页解析结果上报（路由 _FWD） |
| `BD_GOOGLE_RESULT_FWD` | background | grabber | 转发到聚合列表 |

## 七、风险与对策

| 风险 | 对策 |
|------|------|
| Google 反爬（sorry 页） | content script 检测验证页 → 提示用户手动验证后「重试导入」 |
| jrants 限流 | 请求间隔 ≥2s；失败提示稍后重试，不产出垃圾结果（沿用 isBlockedPage） |
| rrwsh 域名变化 | hosts 配置驱动，域名变更只改配置 |
| 多标签打扰 | Google 标签复用（已存在同 sitesearch 标签则激活不新建） |

## 八、验证方式（红线 3：用户实测）

1. 版本徽标核对（v0.1.00X）后重新加载 dist/
2. 聚合搜索：关键词 `cosplay` → 勾选 jrants/pixibb/rrwsh → 后台 fetch 组结果（封面/名称/张数正确）
3. 勾选 hitxhot/kaizty → 自动打开 Google 搜索标签 → 结果自动回填聚合列表（张数未知占位）
4. 点卡片 → 新标签打开相册页（rrwsh 结果打开的是 rrwsh 域，可正常访问）
5. 勾选批量抓取 → 下载正常
6. 发现问题 → 贴日志（[view]/[buondua] 前缀）定位
