# FP-016 标签云 v2（词典命中 + 同义归并 + 分组筛选 + 自定义词典）

> 立项：2026-09-29（用户指示）｜状态：已实施（编码 + 纯逻辑实测通过，待用户实测）
> 关联：FP-006 标签云（本次为重构，FP-006 规则由本方案取代）

## 1. 需求（用户指示）

「现有标签云功能不够完善：罗列不足，有不够匹配成人内容标签。你看怎么重新设计。」

用户确认的四项决策：

1. 词典由开发侧编写（中/英/日/韩四语初始词典）
2. 界面改为**分类分组 + 筛选 chip**
3. 默认阈值放量：**最小相册 5 / 最小用户 1**（UI 可调）
4. **本期就做**自定义标签 + 屏蔽词（持久化 + 导入导出）

## 2. 现状诊断（FP-006 的六个结构性问题）

| # | 问题 | 原代码依据 | 后果 |
|---|------|-----------|------|
| 1 | 只收首字母大写的英文，小写英文整条丢失 | 原 `extractTags` 的 `^[A-Z][a-z']{1,}$` | `black lace lingerie`、`school uniform` 不产生标签 |
| 2 | 成人向核心词被当噪音过滤 | 原 STOP 表含 `sexy/naked/tits/onlyfans/amateur/hardcore/softcore/无码/福利/福利姬` | 最有检索价值的词被主动丢弃 |
| 3 | 分类只有 7 类，无成人向类别 | 原 `TagCategory` | 恋物/行为/道具/身材/关系 无处归类 |
| 4 | 无同义归并 | 仅 4 条硬编码 `PINYIN_MERGE` | 「黑丝/丝袜/pantyhose/stockings」各算一份，集体到不了阈值 |
| 5 | 阈值写死且偏高（10/2） | 原 `TAG_MIN_ALBUMS=10` | 长尾精准标签永不出现 |
| 6 | 主题/IP 靠整段全等命中 | 原 `THEMES.has(整段)` | 「原神甘雨」整段不等于「原神」→ IP 标签漏抓 |

## 3. 方案

### 3.1 双通道提取

- **词典通道**（新增）：四语分类词典 `src/lib/tag-dict.ts`（约 290 条），每条 = 标准名 + 分类 + 同义词；对相册名做
  - 中文/日文/韩文：包含匹配（编译成一条长正则，长词优先）
  - 英文：`(?<![a-z0-9])…(?![a-z0-9])` 词边界匹配（避免 `ol` 命中 `gold`）
  - 命中的同义词一律**归并到标准名**计数（例：黑丝/白丝/网袜/pantyhose/stockings → **丝袜**）
  - 命中区间去重（长命中优先），避免「黑丝袜」同时计入「黑丝」与「丝袜」
- **自由通道**（保留并修正）：@引用 / 韩语名 / 中日文演员名 / 英文演员名（连续首字母大写 ≤3 词）/ 未收录小写词（≥4 字母）
  - **避让词典**：字面已是词典词、或包含/被包含于某条命中原文时不再重复产出（解决「胶衣 + latex」并存）

### 3.2 分类扩到 14 类

`japanese 演员 / korean 韩语 / ip 作品角色 / theme 主题 / scene 场景 / clothes 服装 / fetish 恋物 / act 行为玩法 / prop 道具 / body 身材特征 / relation 关系人数 / brand 品牌 / english 英文 / at 引用`

成人向分类（恋物 / 行为玩法 / 身材特征 / 关系人数 / 场景）为本次新增，词条作为**匹配关键字**使用。

### 3.3 停用词表重做

原 STOP 中的成人向有效词移入词典成为正式标签；STOP 只保留真正无信息量的词（月份、model/写真/图集/套图/photo/set/vol…）。另加英文功能词表（the/and/with/black/white…）避免噪音。

### 3.4 阈值与展示

- 控件：Top N（20~1000，默认 200）、最小相册（默认 5）、最小用户（默认 1）、「含 URL slug」开关
- 展示：分类分组卡片（左色条 + 分类名 + 词数 + 标签 pill），字号按命中数
- 分类 chip 单选筛选（全部 / 各分类 + 计数）

### 3.5 自定义词典与屏蔽词（storage `tag_custom`）

- 添加自定义标签（词 + 分类）→ 立即参与统计（可补词典盲区，如特定演员名）
- 屏蔽词：标签上的 `×` 或输入框添加；被屏蔽标签另列一行可点击取消
- 词典导入/导出（JSON）

## 4. 数据流

```
producerDb.entries[].albums[].name(+slug 可选)
  → buildMatcher(内置词典 + 自定义词典) 预编译正则
  → 词典通道命中（同义归并 + 区间去重） + 自由通道（避让词典字面）
  → 按标准名统计（相册数 / 覆盖用户数） → 屏蔽词过滤 → 阈值过滤 → Top N
  → UI 分类分组展示；点击标签 → ③区关键词检索
自定义词典/屏蔽词 ⇄ background（IMG_TAG_DICT_GET / SAVE）⇄ storage tag_custom
```

## 5. 消息协议

| type | 说明 |
|------|------|
| `IMG_TAG_GET` | 统计标签（`topN` / `minAlbums` / `minUsers` / `includeSlug`；合并自定义词典与屏蔽词） |
| `IMG_TAG_DICT_GET` | 读取自定义词典与屏蔽词 |
| `IMG_TAG_DICT_SAVE` | 保存自定义词典与屏蔽词 |

## 6. 纯逻辑实测（开发侧，临时脚本跑完即删）

样本（相册名 → 命中）：

| 输入 | 输出 |
|------|------|
| `黑丝袜 制服 原神甘雨 cos` | 丝袜 / 制服 / 原神 / 甘雨 / 角色扮演（无「黑丝袜」「原神甘雨」噪音） |
| `Black Lace Lingerie School Uniform` | 蕾丝 / 内衣 / 制服（小写英文不再丢失，也无 black 噪音） |
| `Emily Willis - latex bondage set` | 束缚 / 胶衣 / emily willis |
| `泳装 沙滩 温泉 浴衣 兔女郎` | 泳装 / 海边 / 温泉 / 和服 / 兔女郎（同义归并生效） |
| `@someuser 双马尾 眼镜 女仆装 猫耳` | 双马尾 / 眼镜 / 女仆装 / 猫耳 / @someuser |

统计与阈值：4 条不同写法的丝袜相册 → 归并为「丝袜 albums=4 users=2」；`minAlbums=3` 时只剩丝袜；屏蔽「胶衣」后该项消失；自定义词 `testword → 测试词` 命中 1；`loadCustomDict` 对非法分类/空词/非字符串屏蔽项容错正常。

性能：**30000 条相册、约 570 个词面 → 561ms**（每次现算；后续库更大可加缓存）。

## 8. 验证方式（用户实测）

1. `npm run build` → 重载扩展 → 抓取页右下角核对 **v0.2.2**
2. 站点适配 → ②区「读取」→ ⑤区「生成标签云」→ 应出**分类分组卡片**（演员/作品角色/服装/恋物/场景…）
3. 点分类 chip → 只看该类；点标签 → ③区自动检索
4. 标签右上 `×` → 该标签进入「已屏蔽」，统计中消失
5. 「自定义词」填一个词 + 选分类 → 添加 → 若库内相册名含该词，立即出现在对应分组
6. 「导出词典」→ 得到 JSON；改完「导入词典」→ 生效
7. 日志面板（debug）应见：`[background/tag] 标签云统计完成 { tags, topN, minAlbums, minUsers, custom, blocked }`

## 9. 待办 / 已知限制

- 词典为初始版本（约 290 条），覆盖不足处用「自定义词」补，后续可继续扩词
- 统计为每次现算（30k 相册约 0.56s）；库继续增大需加缓存（库变更置脏）
- 标签检索仍为**相册名字符串包含匹配**（与 FP-006 一致），未做同义扩展检索（点击「丝袜」只匹配含「丝袜」字面的相册名）
- 自定义词典目前不支持「同义词编辑」（只支持新增标准名 + 分类），需要时再扩
