# FP-015 手动星级评定（生产者库第 5 列评星）

> 立项：2026-09-29（用户指示）｜状态：已实施（编码完成，待用户实测）
> 关联：FP-005 关注链扩散检索（生产者库 / 综合评分）

## 1. 需求

生产者库「入度 Top」列表当前只有第 4 列入度有值：第 3 列（得分）与第 5 列（相册数）均为空闲 `-`。

用户要求：

1. 把**第 5 列（原相册数栏）改为 5 颗空白星级**，由用户在界面上**手动点击评星**（1~5 星，再点同一颗取消）。
2. 星级**计入综合评分，权重占 50%**。
3. 剩余 50% 仍按②区「入度权重」输入框的比例分配给入度与相册数（用户选择）。
4. **未评星（0 星）= 星级项 0 分**（用户选择）。

## 2. 场景

1. 用户跑完扩散 → 生产者库累积入度；点「读取」看到「入度 Top」列表。
2. 对每个用户按自己的偏好点击第 5 列的星星（例如中意的生产者给 5 星）。
3. 评星立即写库并持久化；「得分 Top」随之重排（星级 50% + 入度/相册数 50%）。
4. 关闭/重开抓取页后星级仍在（存 `producer_db` 的 `starRating` 字段）。

## 3. 数据流

```
grabber（入度 Top 第 5 列点击）
  → sendMessage IMG_DB_SET_STAR { username, stars }
  → background：setStarRating(producerDb, username, stars) → storageSet('producer_db')
  → 返回 { ok, starRating }
  → grabber：本地即时点亮 + loadDbStats() 刷新三组排行
  → IMG_DB_GET 返回 rankDegree[].starRating（含星级）用于渲染
```

## 4. 评分公式（FP-015 起）

```
score = 0.5 × (stars / 5) + 0.5 × [ w1 × logNorm(入度, max入度) + w2 × logNorm(相册数, max相册数) ]
```

- `stars` ∈ {0,1,2,3,4,5}，缺省 / 0 → 星级项 0 分
- `w1` = ②区「入度权重」输入框（默认 60%），`w2 = 1 − w1`
- 常量：`STAR_WEIGHT = 0.5`、`MAX_STARS = 5`（`src/lib/producer-db.ts`）

## 5. 界面

| 项 | 说明 |
|----|------|
| 位置 | ②区「入度 Top」列表第 5 列（原 `user-albums` 栏） |
| 控件 | 5 个字符星：未评 `☆`（灰）、已评 `★`（金 `#e8c06a`） |
| 交互 | 点第 N 颗 = N 星；再点同一颗 = 取消（0 星）；列表重绘后状态由后台数据恢复 |
| 列宽 | `.degree-list .user-row` 单列覆盖为 `24px 1fr 46px 46px 66px`（其余两组排行布局不变）|
| 其他列表 | 「得分 Top」「相册数 Top」「会话列表」不改（本次范围仅入度 Top）|

## 6. 权限

无新增权限，无新增网络请求（纯本地写 storage）。

## 7. 数据模型

`ProducerEntry` 新增可选字段：

| 字段 | 类型 | 说明 |
|------|------|------|
| `starRating` | `number?` | 手动星级 0~5；0 / 缺省 = 未评星。`loadDb` 容错夹取，0 不落字段 |

合并规则（`mergeDb`）：星级为人工评定，**本地已评保留本地**，本地未评才采纳外部值。

**回归自查**：得分 Top / 区间检索排序结果会因星级变化（预期行为）；相册数 Top 不受影响；`resetConfirmations` 不清除星级（星级与相册确认相互独立）；导入导出（`IMG_DB_IMPORT`）走 `loadDb` 容错，星级随库导入。

## 9. 验证方式（用户实测）

1. `npm run build` → `chrome://extensions` 重载 → 打开抓取页（右下角核对版本徽标）
2. 多页图站 → 站点适配 → ②区点「读取」→ 入度 Top 列表第 5 列出现 5 颗 `☆`
3. 点第 3 颗 → 变 3 颗 `★` + 状态栏提示 + 「得分 Top」重排；再点第 3 颗 → 回到 0 星
4. 关闭抓取页重新打开 → 点「读取」→ 星级仍在（持久化生效）
5. 日志面板（debug）应见：`[background/score] 手动星级已设置 { username, stars }`
